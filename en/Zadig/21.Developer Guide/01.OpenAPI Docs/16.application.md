## Search Applications

**Request**

```text
POST /openapi/application/applications/search
```

**Body Parameters**

| Parameter | Type | Description | Required |
| --- | --- | --- | --- |
| `page` | integer | Page number, starting at 1. Defaults to 1 if omitted or less than or equal to 0 | No |
| `page_size` | integer | Number of items per page. Defaults to 20 if omitted or less than or equal to 0 | No |
| `query` | string | Case-insensitive substring search by application name or key | No |
| `filters` | object[] | Filter conditions combined with AND. Also applied when `query` is provided | No |
| `sort_by` | string | Sort field. Defaults to `update_time`; supports the same fields as filtering | No |
| `sort_order` | string | `asc` for ascending or `desc` for descending. Defaults to `asc` | No |

**Filter Parameters**

| Parameter | Type | Description | Required |
| --- | --- | --- | --- |
| `field` | string | Field to filter, as listed below | Yes |
| `verb` | string | Operator supported by the field type | Yes |
| `value` | string / number / boolean / string[] | Filter value. Omit for `is_empty` and `is_not_empty`; required for all other operators | Depends on the operator |

| Filter Field | Value Type |
| --- | --- |
| `name`, `key`, `project`, `type`, `owner`, `description`, `testing_service_name`, `production_service_name` | string |
| `repository.codehost_id` | number, code provider ID |
| `create_time`, `update_time` | number, Unix timestamp in seconds |
| `custom_fields.<field_key>` | Depends on the custom field type |

| Field Type | Supported Operators | Value Type |
| --- | --- | --- |
| Text, single select, link, user, user group, project | `=`, `!=`, `begins_with`, `not_begins_with`, `ends_with`, `not_ends_with`, `contains`, `not_contains` | string |
| Text, single select, link, user, user group, project | `has_any_of`: matches any of the supplied values | string[] |
| Number, date time | `=`, `!=`, `<`, `<=`, `>`, `>=` | number |
| Boolean | `is` | boolean |
| Multi select | `contains`, `not_contains`: includes or excludes a specific option | string |
| Multi select | `has_any_of`: includes any of the supplied options | string[] |
| Multi select | `is_empty`, `is_not_empty` | Omit |

String matching is case-insensitive. Negated string filters and the multi-select `not_contains` operator return only applications where the field exists, is not `null`, and satisfies the filter condition.

**Request Example**

This example assumes that the single-select field `priority` has been created with options `P0` and `P1`.

```json
{
  "page": 1,
  "page_size": 20,
  "query": "order",
  "filters": [
    {"field": "project", "verb": "=", "value": "shop"},
    {"field": "custom_fields.priority", "verb": "=", "value": "P0"}
  ],
  "sort_by": "update_time",
  "sort_order": "desc"
}
```

**Response Parameters**

| Parameter | Type | Description |
| --- | --- | --- |
| `items` | object[] | Applications on the current page. See Get Application Details for the application object |
| `page` | integer | Current page number |
| `page_size` | integer | Number of items per page |
| `total` | integer | Total number of matching applications |

**Response Example**

Only fields needed to use the API are shown.

```json
{
  "items": [
    {
      "id": "6aff00000000000000000001",
      "name": "Order Service",
      "key": "order-service",
      "project": "shop",
      "type": "service",
      "owner": "",
      "description": "Order processing service",
      "repository": {
        "codehost_id": 1,
        "repo_owner": "shop-team",
        "repo_name": "order-service"
      },
      "testing_service_name": "order-service",
      "production_service_name": "",
      "custom_fields": {"priority": "P0"},
      "create_time": 1795132800,
      "update_time": 1795132800
    }
  ],
  "page": 1,
  "page_size": 20,
  "total": 1
}
```

## Get Application Details

**Request**

```text
GET /openapi/application/applications/:id
```

The path parameter `id` is the application ID returned by Search Applications or Create Application. The application ID differs from its unique key, `key`.

**Response Parameters**

| Parameter | Type | Description |
| --- | --- | --- |
| `id` | string | Application ID, used to retrieve, update, delete, or list associated environments |
| `name` | string | Application name |
| `key` | string | Unique application key, which cannot be changed after creation |
| `project` | string | Key of the associated project |
| `type` | string | Application type |
| `owner` | string | User ID of the owner |
| `description` | string | Application description |
| `repository.codehost_id` | integer | Code provider ID |
| `repository.repo_owner` | string | User or organization that owns the repository |
| `repository.repo_name` | string | Repository name |
| `testing_service_name` | string | Associated test service name |
| `production_service_name` | string | Associated production service name |
| `custom_fields` | object | Custom field values, indexed by field key |
| `create_time` | integer | Creation time, as a Unix timestamp in seconds |
| `update_time` | integer | Last update time, as a Unix timestamp in seconds |

`repository` is omitted when no code repository is associated with the application.

**Response Example**

```json
{
  "id": "6aff00000000000000000001",
  "name": "Order Service",
  "key": "order-service",
  "project": "shop",
  "type": "service",
  "owner": "",
  "description": "Order processing service",
  "repository": {
    "codehost_id": 1,
    "repo_owner": "shop-team",
    "repo_name": "order-service"
  },
  "testing_service_name": "order-service",
  "production_service_name": "",
  "custom_fields": {"priority": "P0"},
  "create_time": 1795132800,
  "update_time": 1795132800
}
```

## Create Application

**Request**

```text
POST /openapi/application/applications
```

**Body Parameters**

| Parameter | Type | Description | Required |
| --- | --- | --- | --- |
| `name` | string | Application name. Must not contain only whitespace | Yes |
| `key` | string | Unique application key. Must not contain only whitespace and cannot be changed after creation | Yes |
| `project` | string | Key of the associated project. Must not contain only whitespace | Yes |
| `type` | string | Application type, as configured in the business model | No |
| `owner` | string | User ID of the owner | No |
| `description` | string | Application description | No |
| `repository` | object | Associated code repository. See the parameters below | No |
| `testing_service_name` | string | Associated test service name. Must belong to the project specified by `project` | No |
| `production_service_name` | string | Associated production service name. Must belong to the project specified by `project` | No |
| `custom_fields` | object | Custom field values. Fields marked as required in the business model must have valid values | Conditional |

**Repository Parameters**

When `repository` is provided, all three parameters below are required and must not contain only whitespace.

| Parameter | Type | Description |
| --- | --- | --- |
| `codehost_name` | string | Name of a code provider integrated with Zadig |
| `repo_owner` | string | User or organization that owns the repository |
| `repo_name` | string | Repository name |

**Request Example**

This example uses the existing project `shop`, test service `order-service`, and code provider `gitlab`. It assumes that the single-select field `priority` has been created.

```json
{
  "name": "Order Service",
  "key": "order-service",
  "project": "shop",
  "type": "service",
  "description": "Order processing service",
  "repository": {
    "codehost_name": "gitlab",
    "repo_owner": "shop-team",
    "repo_name": "order-service"
  },
  "testing_service_name": "order-service",
  "custom_fields": {"priority": "P0"}
}
```

**Successful Response**

Returns the created application object. See Get Application Details for field descriptions. The system generates the `id` and timestamps.

## Bulk Import Applications

**Request**

```text
POST /openapi/application/applications/bulk
```

The request body is an array of application objects. Each object uses the same parameters and validation rules as Create Application.

**Request Example**

```json
[
  {"name": "Order Service", "key": "order-service", "project": "shop"},
  {"name": "Payment Service", "key": "payment-service", "project": "shop"}
]
```

If the business model includes required custom fields, provide the corresponding `custom_fields` in every object.

Returns `{"message":"success"}` on success. If an import fails, query the applications already imported before deciding which items to retry, to avoid duplicate creation.

## Update Application

**Request**

```text
PUT /openapi/application/applications/:id
```

The path parameter `id` is the application ID. Body parameters are the same as Create Application. `name`, `key`, and `project` are required, and `key` must match its existing value. Include optional settings and custom fields that you want to retain. The following rules apply to `repository`:

| repository Input | Behavior |
| --- | --- |
| Omitted or `null` | Retains the existing repository association |
| Complete object | Updates the repository association using `codehost_name`, `repo_owner`, and `repo_name` |
| `{}`, a missing required nested field, or a required nested field containing only whitespace | Fails parameter validation |

**Request Example**

```json
{
  "name": "Order Service",
  "key": "order-service",
  "project": "shop",
  "type": "service",
  "owner": "",
  "description": "Order lookup and processing service",
  "repository": {
    "codehost_name": "gitlab",
    "repo_owner": "shop-team",
    "repo_name": "order-service"
  },
  "testing_service_name": "order-service",
  "production_service_name": "",
  "custom_fields": {"priority": "P1"}
}
```

Returns `{"message":"success"}` on success.

## Delete Application

**Request**

```text
DELETE /openapi/application/applications/:id
```

The path parameter `id` is the application ID. Deleting an application removes its associations with test and production services. The services themselves are retained.

Returns `{"message":"success"}` on success.

## List Associated Environments

**Request**

```text
GET /openapi/application/applications/:id/envs
```

The path parameter `id` is the application ID. Returns environments where the associated test or production service is deployed. Returns an empty array if no environments match.

**Response Parameters**

| Parameter | Type | Description |
| --- | --- | --- |
| `project_name` | string | Project key |
| `env_name` | string | Environment name |
| `env_alias` | string | Environment alias |
| `production` | boolean | Whether this is a production environment |
| `name` | string | Service display name |
| `type` | string | Deployment type, such as `k8s`, `helm`, or `pm` |
| `status` | string | Service status. Values depend on the deployment type |
| `images` | string[] | Service images, for deployment types that return image information |
| `chart_version` | string | Helm Chart version |
| `update_time` | integer | Last update time, as a Unix timestamp in seconds. Returns 0 if unavailable |
| `error` | string | Error retrieving information for this entry. Empty if no error occurred |

**Response Example**

```json
[
  {
    "project_name": "shop",
    "env_name": "dev",
    "env_alias": "Development",
    "production": false,
    "name": "order-service",
    "type": "k8s",
    "status": "Running",
    "images": ["registry.example.com/shop/order-service:v1.0.0"],
    "chart_version": "",
    "update_time": 1795132800,
    "error": ""
  }
]
```

## List Model Fields

**Request**

```text
GET /openapi/application/fields
```

Returns definitions for built-in and custom fields. Set built-in fields through the corresponding application parameters. Set custom fields through `custom_fields`; for example, `{"custom_fields":{"priority":"P0"}}` sets the value of `priority`.

**Response Parameters**

| Parameter | Type | Description |
| --- | --- | --- |
| `id` | string | Field ID, used to update or delete the field |
| `key` | string | Field key |
| `name` | string | Field display name |
| `type` | string | Field type, as listed below |
| `default` | Depends on the field type | Default field value |
| `options` | string[] | Available options for single-select and multi-select fields |
| `unique` | boolean | Whether the field is configured to require unique values |
| `required` | boolean | Whether the field is required |
| `show_in_list` | boolean | Whether the field is displayed in the application list |
| `description` | string | Field description |
| `source` | string | Field origin: `builtin` for built-in fields or `custom` for custom fields |
| `create_time` | integer | Creation time, as a Unix timestamp in seconds |
| `update_time` | integer | Last update time, as a Unix timestamp in seconds |

**Response Example**

The following example shows a custom field.

```json
[
  {
    "id": "6aff00000000000000000002",
    "key": "priority",
    "name": "Priority",
    "type": "single_select",
    "default": "P1",
    "options": ["P0", "P1"],
    "unique": false,
    "required": false,
    "show_in_list": true,
    "description": "Application priority",
    "source": "custom",
    "create_time": 1795132800,
    "update_time": 1795132800
  }
]
```

**Custom Field Types and Value Formats**

| Type | Meaning | Value Type in custom_fields |
| --- | --- | --- |
| `text` | Text | string |
| `number` | Number | number |
| `bool` | Boolean | boolean |
| `datetime` | Date time | number |
| `single_select` | Single select | string, must be one of the `options` |
| `multi_select` | Multi select | string[], each value must be one of the `options` |
| `link` | Link | string |
| `user` | User | string, user ID |
| `user_group` | User group | string, user group ID |
| `project` | Project | string, project key |

## Create Model Field

**Request**

```text
POST /openapi/application/fields
```

**Body Parameters**

| Parameter | Type | Description | Required |
| --- | --- | --- | --- |
| `key` | string | Unique field key, used as a key in `custom_fields`. Must not contain only whitespace | Yes |
| `name` | string | Field display name. Must not contain only whitespace | Yes |
| `type` | string | Custom field type. See List Model Fields | Yes |
| `default` | Depends on the field type | Default value, using the format required by the field type | No |
| `options` | string[] | Nonempty option list, required for single-select and multi-select fields. Omit for other types | Conditional |
| `unique` | boolean | Whether values are configured as unique. Defaults to `false`; cannot be `true` for multi-select fields | No |
| `required` | boolean | Whether the field is required. Defaults to `false` | No |
| `show_in_list` | boolean | Whether the field is displayed in the application list. Defaults to `false` | No |
| `description` | string | Field description | No |

**Request Example**

```json
{
  "key": "priority",
  "name": "Priority",
  "type": "single_select",
  "default": "P1",
  "options": ["P0", "P1"],
  "unique": false,
  "required": false,
  "show_in_list": true,
  "description": "Application priority"
}
```

Returns the created field object. See List Model Fields for field descriptions.

## Update Model Field

**Request**

```text
PUT /openapi/application/fields/:id
```

The path parameter `id` is the field ID returned by List Model Fields. Body parameters are the same as Create Model Field. Submit the complete updated field definition, including defaults, options, and display settings that you want to retain.

**Request Example**

```json
{
  "key": "priority",
  "name": "Priority",
  "type": "single_select",
  "default": "P1",
  "options": ["P0", "P1", "P2"],
  "unique": false,
  "required": false,
  "show_in_list": true,
  "description": "Application priority"
}
```

Returns `{"message":"success"}` on success.

## Delete Model Field

**Request**

```text
DELETE /openapi/application/fields/:id
```

The path parameter `id` is the field ID. Deleting a custom field also removes its values from applications.

Returns `{"message":"success"}` on success.
