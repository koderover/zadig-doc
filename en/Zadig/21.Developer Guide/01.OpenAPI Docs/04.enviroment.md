## View Helm Service Values Configuration

::: tip
1. Applicable to Zadig services in Helm Chart projects. Chart-only releases are not supported.
2. Returns the override configuration saved in the environment for the service, i.e. `values_yaml` and `override_kvs`. Chart default Values are not included.
3. To view the Values actually deployed in the cluster, use the `View Helm Release Values` API below.
4. The returned `revision` can be used as `expected_revision` when updating Values.
:::

**Request**

```
GET /openapi/environments/helm/<environmentKey>/services/<serviceName>/values?projectKey=<projectKey>
```

**Path Parameters**

| Parameter Name   | Description     | Type   | Required |
| ---------------- | --------------- | ------ | -------- |
| `environmentKey` | Environment Key | string | Yes      |
| `serviceName`    | Service Name    | string | Yes      |

**Query Parameters**

| Parameter Name | Description                                           | Type   | Required |
| -------------- | ----------------------------------------------------- | ------ | -------- |
| `projectKey`   | Project Key                                           | string | Yes      |
| `production`   | Whether it is a production environment, default `false` | bool   | No       |
| `type`         | Service type, must be `service` if specified          | string | No       |

**Response Description**

| Parameter Name | Description                                     | Type                        |
| -------------- | ----------------------------------------------- | --------------------------- |
| `release_name` | Helm Release name                               | string                      |
| `revision`     | Current latest revision of the environment service | int                         |
| `values_yaml`  | Override Values YAML saved in the environment   | string                      |
| `override_kvs` | Override KV list saved in the environment       | [][OverrideKV](#OverrideKV) |

**Response Example**

::: details
```json
{
    "release_name": "demo-dev-service1",
    "revision": 3,
    "values_yaml": "replicaCount: 2\nimage:\n  tag: 20250711170816-5-main\n",
    "override_kvs": [
        {
            "key": "resources.limits.cpu",
            "value": "200m"
        }
    ]
}
```
:::

## View Helm Release Values

::: tip
1. Applicable to Zadig services in Helm Chart projects. Chart-only releases are not supported.
2. Returns the Values actually deployed by the service's Helm Release in the cluster, i.e. the merged, effective result.
:::

**Request**

```
GET /openapi/environments/helm/<environmentKey>/services/<serviceName>/release/values?projectKey=<projectKey>
```

**Path Parameters**

| Parameter Name   | Description     | Type   | Required |
| ---------------- | --------------- | ------ | -------- |
| `environmentKey` | Environment Key | string | Yes      |
| `serviceName`    | Service Name    | string | Yes      |

**Query Parameters**

| Parameter Name | Description                                                                                                         | Type   | Required |
| -------------- | ------------------------------------------------------------------------------------------------------------------- | ------ | -------- |
| `projectKey`   | Project Key                                                                                                         | string | Yes      |
| `production`   | Whether it is a production environment, default `false`                                                            | bool   | No       |
| `all_values`   | Whether to return all Values (including Chart defaults), default `false`, i.e. only the Values supplied at deployment | bool   | No       |
| `type`         | Service type, must be `service` if specified                                                                        | string | No       |

**Response Description**

| Parameter Name | Description                  | Type   |
| -------------- | ---------------------------- | ------ |
| `values_yaml`  | Values YAML of the Helm Release | string |

**Response Example**

::: details
```json
{
    "values_yaml": "fullnameOverride: service1\nimage:\n  repository: koderover.tencentcloudcr.com/test/service1\n  tag: 20250711170816-5-main\nreplicaCount: 2\n"
}
```
:::

## Preview Helm Service Values Changes

::: tip
1. Applicable to Zadig services in Helm Chart projects. Chart-only releases are not supported.
2. Only computes the full Values before and after the change. Nothing is saved or deployed.
3. The request body is the same as the `Update Helm Service Values` API. Returns 409 if `expected_revision` does not match the current revision.
:::

**Request**

```
POST /openapi/environments/helm/<environmentKey>/services/<serviceName>/values/preview?projectKey=<projectKey>
```

**Path Parameters**

| Parameter Name   | Description     | Type   | Required |
| ---------------- | --------------- | ------ | -------- |
| `environmentKey` | Environment Key | string | Yes      |
| `serviceName`    | Service Name    | string | Yes      |

**Query Parameters**

| Parameter Name | Description                                           | Type   | Required |
| -------------- | ----------------------------------------------------- | ------ | -------- |
| `projectKey`   | Project Key                                           | string | Yes      |
| `production`   | Whether it is a production environment, default `false` | bool   | No       |

**Body Parameters**

See the body parameters of [Update Helm Service Values](#update-helm-service-values).

**Body Parameter Example**

::: details
```json
{
    "expected_revision": 3,
    "values_yaml": "replicaCount: 3\n",
    "value_merge_strategy": "reuse-values"
}
```
:::

**Response Description**

| Parameter Name         | Description                          | Type   |
| ---------------------- | ------------------------------------ | ------ |
| `current_release_name` | Helm Release name before the change  | string |
| `latest_release_name`  | Helm Release name after the change   | string |
| `current_values_yaml`  | Full Values YAML before the change   | string |
| `latest_values_yaml`   | Full Values YAML after the change    | string |

**Response Example**

::: details
```json
{
    "current_release_name": "demo-dev-service1",
    "latest_release_name": "demo-dev-service1",
    "current_values_yaml": "fullnameOverride: service1\nimage:\n  tag: 20250711170816-5-main\nreplicaCount: 2\n",
    "latest_values_yaml": "fullnameOverride: service1\nimage:\n  tag: 20250711170816-5-main\nreplicaCount: 3\n"
}
```
:::

## Update Helm Service Values

::: tip
1. Applicable to Zadig services in Helm Chart projects. Chart-only releases are not supported.
2. The configuration is saved and then deployed asynchronously in the background. A successful response does not mean the deployment has finished; check the service status to confirm the result.
3. Returns 409 if `expected_revision` does not match the current revision, or if the environment is being updated.
:::

**Request**

```
PUT /openapi/environments/helm/<environmentKey>/services/<serviceName>/values?projectKey=<projectKey>
```

**Path Parameters**

| Parameter Name   | Description     | Type   | Required |
| ---------------- | --------------- | ------ | -------- |
| `environmentKey` | Environment Key | string | Yes      |
| `serviceName`    | Service Name    | string | Yes      |

**Query Parameters**

| Parameter Name | Description                                           | Type   | Required |
| -------------- | ----------------------------------------------------- | ------ | -------- |
| `projectKey`   | Project Key                                           | string | Yes      |
| `production`   | Whether it is a production environment, default `false` | bool   | No       |

**Body Parameters**

| Parameter Name            | Description                                                                                                                                                                                                                       | Type                        | Required |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- | -------- |
| `expected_revision`       | Expected current revision, taken from `revision` returned by the `View Helm Service Values Configuration` API; must be greater than or equal to 0                                                                                   | int                         | Yes      |
| `values_yaml`             | New override Values YAML; cannot be used when auto sync is enabled; cannot be used together with `sync_values_from_source`                                                                                                        | string                      | No       |

3. Test and production environments use the same request paths, distinguished by the `production` parameter.
