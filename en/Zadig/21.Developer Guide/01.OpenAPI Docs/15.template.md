## Get Chart Template List

Returns the available Chart templates in the template library and the system variables supported by the templates.

**Request**

```
GET /openapi/templates/charts
```

**Permission**

The caller must have view permission for the template library.

**Response Description**

| Parameter Name     | Type                                | Description          |
| ------------------ | ----------------------------------- | -------------------- |
| `system_variables` | [][SystemVariable](#SystemVariable) | System variable list, sorted by `key` |
| `chart_templates`  | [][ChartTemplate](#ChartTemplate)   | Chart template list  |

<h4 id="SystemVariable">SystemVariable Parameter Description</h4>

| Parameter Name | Type   | Description   |
| -------------- | ------ | ------------- |
| `key`          | string | Variable name |
| `description`  | string | Variable description, omitted when empty |

<h4 id="ChartTemplate">ChartTemplate Parameter Description</h4>

| Parameter Name | Type   | Description          |
| -------------- | ------ | -------------------- |
| `name`         | string | Template name        |
| `codehost_id`  | int    | Code host ID         |
| `owner`        | string | Repository owner     |
| `namespace`    | string | Repository namespace |
| `repo`         | string | Repository name      |
| `path`         | string | Template path        |
| `branch`       | string | Branch name          |

**Response Example**

```json
{
    "system_variables": [
        {
            "key": "$T-Project$",
            "description": "Project name"
        }
    ],
    "chart_templates": [
        {
            "name": "demo",
            "codehost_id": 1,
            "owner": "koderover",
            "namespace": "charts",
            "repo": "demo-chart",
            "path": "charts/demo",
            "branch": "main"
        }
    ]
}
```

## Get K8s YAML Template List

**Request**

```
GET /openapi/templates/yaml?pageNum=<current page number>&pageSize=<current page display count>
```

**Permission**

The caller must have view permission for the template library. Without that permission, `projectKey` must be passed, and the caller must be an administrator of that project or have create permission for services (including production services) in that project.

**Query Parameter Description**

| Parameter Name | Description                                                              | Type   | Required |
| -------------- | ------------------------------------------------------------------------ | ------ | -------- |
| `projectKey`   | Project key, required without template library view permission          | string | No       |
| `pageNum`      | Current page number for pagination, must be greater than 0, default value: 1 | int | No       |
| `pageSize`     | Number of items per page, must be greater than 0, default value: 20      | int    | No       |

**Response Description**

| Parameter Name   | Type                            | Description        |
| ---------------- | ------------------------------- | ------------------ |
| `total`          | int                             | Total templates    |
| `yaml_templates` | [][YamlTemplate](#YamlTemplate) | YAML template list |

<h4 id="YamlTemplate">YamlTemplate Parameter Description</h4>

| Parameter Name  | Type              | Description                                                          |
| --------------- | ----------------- | -------------------------------------------------------------------- |
| `id`            | string            | Template ID                                                          |
| `name`          | string            | Template name                                                        |
| `source`        | string            | Template source; for templates synced from a repository, the code host type |
| `codehostID`    | int               | Code host ID                                                         |
| `repo_owner`    | string            | Repository owner                                                     |
| `namespace`     | string            | Repository namespace                                                 |
| `repo`          | string            | Repository name                                                      |
| `path`          | string            | Template file path                                                   |
| `branch`        | string            | Branch name                                                          |
| `remote_name`   | string            | Remote name                                                          |
| `load_from_dir` | bool              | Whether to load from a directory                                     |
| `commit`        | [Commit](#Commit) | Commit information at sync time                                      |

> Fields other than `id` and `name` are omitted when empty.

<h4 id="Commit">Commit Parameter Description</h4>

| Parameter Name | Type   | Description    |
| -------------- | ------ | -------------- |
| `sha`          | string | Commit SHA     |
| `message`      | string | Commit message |

**Response Example**

```json
{
    "total": 2,
    "yaml_templates": [
        {
            "id": "6650a7e1b2c3d4e5f6a7b8c9",
            "name": "nginx-deployment"
        },
        {
            "id": "6650a7e1b2c3d4e5f6a7b8ca",
            "name": "service-template",
            "source": "gitlab",
            "codehostID": 1,
            "repo_owner": "koderover",
            "namespace": "koderover",
            "repo": "k8s-templates",
            "path": "templates/service.yaml",
            "branch": "main",
            "remote_name": "origin",
            "commit": {
                "sha": "3f2a1b9c8d7e6f5a4b3c2d1e0f9a8b7c6d5e4f3a",
                "message": "update service template"
            }
        }
    ]
}
```

## Get K8s YAML Template Details

**Request**

```
GET /openapi/templates/yaml/:id
```

**Permission**

Same as [Get K8s YAML Template List](#get-k8s-yaml-template-list).

**Path Parameter Description**

| Parameter Name | Description | Type   | Required |
| -------------- | ----------- | ------ | -------- |
| `id`           | Template ID | string | Yes      |

**Query Parameter Description**

| Parameter Name | Description                                                     | Type   | Required |
| -------------- | --------------------------------------------------------------- | ------ | -------- |
| `projectKey`   | Project key, required without template library view permission | string | No       |

**Response Description**

| Parameter Name         | Type                                      | Description                         |
| ---------------------- | ----------------------------------------- | ----------------------------------- |
| `id`                   | string                                    | Template ID                         |
| `name`                 | string                                    | Template name                       |
| `content`              | string                                    | Template content                    |
| `variable_yaml`        | string                                    | Template variables in YAML format   |
| `service_variable_kvs` | [][ServiceVariableKV](#ServiceVariableKV) | Template variable definitions       |
| `source`               | string                                    | Template source                     |
| `codehostID`           | int                                       | Code host ID                        |
| `repo_owner`           | string                                    | Repository owner                    |
| `namespace`            | string                                    | Repository namespace                |
| `repo_name`            | string                                    | Repository name                     |
| `path`                 | string                                    | Template file path                  |
| `branch_name`          | string                                    | Branch name                         |
| `remote_name`          | string                                    | Remote name                         |
| `load_from_dir`        | bool                                      | Whether to load from a directory    |
| `commit`               | [Commit](#Commit)                         | Commit information at sync time     |

> `source` and the fields after it are omitted when empty.

<h4 id="ServiceVariableKV">ServiceVariableKV Parameter Description</h4>

| Parameter Name | Type     | Description                                                     |
| -------------- | -------- | --------------------------------------------------------------- |
| `key`          | string   | Variable name                                                   |
| `value`        | any      | Default value of the variable                                   |
| `type`         | string   | Variable type, supports `string`, `enum`, `bool`, `yaml`        |
| `options`      | []string | List of options, used when `type` is `enum`                     |
| `desc`         | string   | Variable description                                            |

**Response Example**

```json
{
    "id": "6650a7e1b2c3d4e5f6a7b8c9",

    "variable_yaml": "Name: nginx\nReplicas: 1\n",
    "service_variable_kvs": [
        {
            "key": "Name",
            "value": "nginx",
            "type": "string",
            "options": [],
            "desc": "Service name"
        },
        {
            "key": "Replicas",
            "value": "1",
            "type": "enum",
            "options": ["1", "2", "3"],
            "desc": "Number of replicas"
        }
    ]
}
```


**Permission**

The caller must have view permission for the template library.

**Path Parameter Description**

| Parameter Name | Description       | Type   | Required |
| -------------- | ----------------- | ------ | -------- |
| `id`           | Build template ID | string | Yes      |

**Response Description**

Returns `id`, `update_time`, `update_by`, and all body fields from [Create Build Template](#create-build-template).

| Parameter Name      | Type                                                | Description                                       |
| ------------------- | --------------------------------------------------- | ------------------------------------------------- |
| `id`                | string                                              | Build template ID                                 |

## Create Build Template

**Request**

```
POST /openapi/templates/builds
```

**Permission**

The caller must have create permission for the template library.

**Body Parameter Description**

| Parameter Name      | Description                                                                                                         | Type                                                | Required |
| ------------------- | ------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- | -------- |
| `name`              | Build template name                                                                                                 | string                                              | Yes      |
| `infrastructure`    | Infrastructure, kubernetes for a Kubernetes cluster, vm for hosts                                                  | string                                              | Yes      |
| `vm_labels`         | Host labels, required when `infrastructure` is vm                                                                   | []string                                            | No       |
| `build_os`          | Build image name, i.e. the name of a build image in system settings, such as `ubuntu 20.04` or a custom image name | string                                              | Yes      |
| `installs`          | Dependent software packages                                                                                         | [][Install](#Install)                               | No       |
| `parameters`        | Custom variables                                                                                                    | [][BuildTemplateParameter](#BuildTemplateParameter) | No       |
| `script_type`       | Script type, supports shell, batch_file, powershell                                                                 | string                                              | Yes      |
| `build_script`      | Build script                                                                                                        | string                                              | Yes      |
| `docker_build_step` | Image build step                                                                                                    | [DockerBuildStep](#BuildTemplateDockerBuildStep)    | No       |
| `advanced_settings` | Advanced settings, the default configuration is used when omitted                                                   | [AdvancedSettings](#BuildTemplateAdvancedSettings)  | No       |

> When `advanced_settings` is omitted, the default configuration is used: timeout 60, resource spec CPU 1000m/4000m and memory 1024Mi/8192Mi, and when the infrastructure is kubernetes, the local cluster and its default scheduling strategy.

<h4 id="Install">Install Parameter Description</h4>

| Parameter Name | Description      | Type   | Required |
| -------------- | ---------------- | ------ | -------- |
| `name`         | Package name     | string | Yes      |
| `version`      | Package version  | string | Yes      |

<h4 id="BuildTemplateParameter">BuildTemplateParameter Parameter Description</h4>

| Parameter Name  | Description                                                     | Type     | Required |
| --------------- | --------------------------------------------------------------- | -------- | -------- |
| `key`           | Variable key                                                    | string   | Yes      |
| `type`          | Variable type, supports string, choice, multi-select            | string   | Yes      |
| `default_value` | Default value of the variable, cannot be empty                  | string   | Yes      |
| `choice_option` | List of options                                                 | []string | No       |
| `choice_value`  | List of selected values, used when `type` is multi-select       | []string | No       |
| `is_credential` | Whether it is sensitive information                             | bool     | No       |
| `description`   | Variable description                                            | string   | No       |
| `required`      | Whether it is required                                          | bool     | No       |

<h4 id="BuildTemplateDockerBuildStep">DockerBuildStep Parameter Description</h4>

| Parameter Name         | Description                                                                          | Type   | Required |
| ---------------------- | ------------------------------------------------------------------------------------ | ------ | -------- |
| `dockerfile_source`    | Dockerfile source, local for the code repository, template for the template library | string | Yes      |
| `build_context_dir`    | Build context directory                                                              | string | Yes      |
| `dockerfile_directory` | Absolute path of the Dockerfile, required when `dockerfile_source` is local          | string | No       |
| `template_name`        | Dockerfile template name, required when `dockerfile_source` is template              | string | No       |
| `build_args`           | Build arguments                                                                      | string | No       |
| `enable_proxy`         | Whether to inject proxy arguments during image build; the system proxy must also be enabled | bool | No |
| `enable_buildkit`      | Whether to enable Buildkit                                                           | bool   | No       |
| `platforms`            | Buildkit build platforms, such as `linux/amd64`, required when `enable_buildkit` is true | string | No |

<h4 id="BuildTemplateAdvancedSettings">AdvancedSettings Parameter Description</h4>

| Parameter Name           | Description                                                                  | Type                                           | Required |
| ------------------------ | ---------------------------------------------------------------------------- | ---------------------------------------------- | -------- |
| `timeout`                | Build timeout, must be greater than 0                                        | int                                            | Yes      |
| `cluster_name`           | Cluster name, required when `infrastructure` is kubernetes                   | string                                         | No       |
| `strategy_name`          | Scheduling strategy name, must be an existing strategy in the selected cluster | string                                       | No       |
| `resource_spec`          | Resource specification                                                       | [ResourceSpec](#BuildTemplateResourceSpec)     | No       |
| `cache_setting`          | Cache configuration                                                          | [CacheSetting](#BuildTemplateCacheSetting)     | No       |
| `storages`               | Storage configuration                                                        | [StorageSetting](#BuildTemplateStorageSetting) | No       |
| `use_host_docker_daemon` | Whether to use the host's docker daemon                                      | bool                                           | No       |
| `privileged_mode`        | Whether to enable privileged mode                                            | bool                                           | No       |
| `custom_annotations`     | Custom annotations                                                           | [][KeyValue](#BuildTemplateKeyValue)           | No       |
| `custom_labels`          | Custom labels                                                                | [][KeyValue](#BuildTemplateKeyValue)           | No       |
| `outputs`                | List of output variable names                                                | []string                                       | No       |

<h4 id="BuildTemplateResourceSpec">ResourceSpec Parameter Description</h4>

| Parameter Name | Description                              | Type   | Required |
| -------------- | ---------------------------------------- | ------ | -------- |
| `cpu_req`      | CPU request, in m                        | int    | No       |
| `cpu_limit`    | CPU limit, in m                          | int    | No       |
| `memory_req`   | Memory request, in Mi                    | int    | No       |
| `memory_limit` | Memory limit, in Mi                      | int    | No       |
| `gpu_limit`    | GPU limit, such as `nvidia.com/gpu: 1`   | string | No       |

> Resource values cannot be negative, and request values cannot exceed limit values.

<h4 id="BuildTemplateCacheSetting">CacheSetting Parameter Description</h4>

| Parameter Name | Description                                                                                  | Type   | Required |
| -------------- | -------------------------------------------------------------------------------------------- | ------ | -------- |
| `enabled`      | Whether to enable caching                                                                    | bool   | No       |
| `cache_dir`    | Custom cache directory; when caching is enabled and this is empty, the workspace is used    | string | No       |

<h4 id="BuildTemplateStorageSetting">StorageSetting Parameter Description</h4>

| Parameter Name        | Description                 | Type                                                 | Required |
| --------------------- | --------------------------- | ---------------------------------------------------- | -------- |
| `enabled`             | Whether to enable storage   | bool                                                 | No       |
| `storages_properties` | List of storage properties  | [][StoragesProperty](#BuildTemplateStoragesProperty) | No       |

<h4 id="BuildTemplateStoragesProperty">StoragesProperty Parameter Description</h4>

| Parameter Name        | Description                                                                                                                      | Type   | Required |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ------ | -------- |
| `provision_type`      | Storage type, dynamic for dynamic provisioning, static for existing storage                                                      | string | Yes      |
| `mount_path`          | Mount path                                                                                                                       | string | Yes      |
| `storage_class`       | Storage class name, required when provision_type is dynamic                                                                      | string | No       |
| `storage_size_in_gib` | Storage size in GiB, required and greater than 0 when provision_type is dynamic                                                  | int    | No       |
| `pvc`                 | PVC name, required when provision_type is static                                                                                 | string | No       |
| `access_mode`         | Access mode, defaults to ReadWriteMany if not set; supports ReadWriteOnce, ReadOnlyMany, ReadWriteMany, ReadWriteOncePod         | string | No       |
| `subpath`             | Volume subpath                                                                                                                   | string | No       |
| `is_temporary`        | Whether it is temporary storage                                                                                                  | bool   | No       |

> Storage properties are validated only when `enabled` is true.

<h4 id="BuildTemplateKeyValue">KeyValue Parameter Description</h4>

| Parameter Name | Description | Type   | Required |

| `key`          | Key         | string | Yes      |
| `value`        | Value       | string | Yes      |

## Update Build Template

> The update is a full overwrite: omitted fields are cleared or reset to their defaults. If `advanced_settings` is omitted, the advanced settings are reset to the default configuration.

**Request**

```
PUT /openapi/templates/builds/:id
```

**Permission**

The caller must have edit permission for the template library.

**Path Parameter Description**

| Parameter Name | Description       | Type   | Required |
| -------------- | ----------------- | ------ | -------- |
| `id`           | Build template ID | string | Yes      |

**Body Parameter Description**

Same as the body parameters of [Create Build Template](#create-build-template).

**Body Parameter Example**

```json
{
    "name": "windows-build",
    "infrastructure": "vm",
    "vm_labels": ["windows"],
    "build_os": "ubuntu 20.04",
    "installs": [],
    "parameters": [],
    "script_type": "powershell",
    "build_script": "cd $env:REPONAME_0\n.\\build.ps1",
    "advanced_settings": {
        "timeout": 30,
        "resource_spec": {
            "cpu_req": 1000,
            "cpu_limit": 2000,
            "memory_req": 1024,
            "memory_limit": 2048
        },
        "cache_setting": {
            "enabled": false,
            "cache_dir": ""
        }
    }
}
```

**Response Description**

```json
{
  "message": "success"
}
```
