## List System Operation Logs

### Request

```
GET /openapi/system/operation
```

### Query

| Parameter Name | Type   | Description                                                                                                         | Required |
| -------------- | ------ | ------------------------------------------------------------------------------------------------------------------- | -------- |
| searchType     | string | Search type, optional values:<br>`all`: all<br>`project`: project<br>`user`: user<br>`function`: function<br>`status`: status code | Yes      |
| projectKey     | string | Project key                                                                                                        | No       |
| username       | string | Username                                                                                                          | No       |
| function       | string | Function                                                                                                          | No       |
| status         | int    | Status code                                                                                                       | No       |
| perPage        | int    | Items per page                                                                                                    | Yes      |
| page           | int    | Page number                                                                                                       | Yes      |

## List Custom Images

> Only system administrators can call this endpoint.

### Request

```
GET /openapi/system/custom_image
```

### Response

| Parameter Name  | Type                          | Description       |
| --------------- | ----------------------------- | ----------------- |
| `custom_images` | [][CustomImage](#CustomImage) | Custom image list |

<h4 id="CustomImage">CustomImage Parameter Description</h4>

| Parameter Name | Type   | Description                                                          |
| -------------- | ------ | -------------------------------------------------------------------- |
| `id`           | string | Image ID                                                             |
| `label`        | string | Image name, used to select the image in build, test and other configurations |
| `value`        | string | Image address                                                        |
| `create_time`  | int    | Creation time, Unix timestamp in seconds                             |
| `update_time`  | int    | Update time, Unix timestamp in seconds                               |
| `update_by`    | string | Updated by                                                           |

```json
{
    "custom_images": [
        {
            "id": "6651a2b3c4d5e6f7a8b9c0d1",
            "label": "go-1.22",
            "value": "koderover.tencentcloudcr.com/test/go-builder:1.22",
            "create_time": 1755300000,
            "update_time": 1755500000,
            "update_by": "admin"
        }
    ]
}
```

## Create Custom Image

> Only system administrators can call this endpoint. The image address cannot duplicate that of an existing image.

### Request

```
POST /openapi/system/custom_image
```

### Body

| Parameter Name | Type   | Description   | Required |
| -------------- | ------ | ------------- | -------- |
| label          | string | Image name    | Yes      |
| value          | string | Image address | Yes      |

```json
{
    "label": "go-1.22",
    "value": "koderover.tencentcloudcr.com/test/go-builder:1.22"
}
```

### Response

```json
{
    "message": "success"
}
```

## Update Custom Image

> Only system administrators can call this endpoint. The image address cannot duplicate that of another image.

### Request

```
PUT /openapi/system/custom_image/:id
```

### Path Parameters

| Parameter Name | Type   | Description | Required |
| -------------- | ------ | ----------- | -------- |
| id             | string | Image ID    | Yes      |

### Body

| Parameter Name | Type   | Description   | Required |
| -------------- | ------ | ------------- | -------- |
| label          | string | Image name    | Yes      |
| value          | string | Image address | Yes      |

```json
{
    "label": "go-1.22",
    "value": "koderover.tencentcloudcr.com/test/go-builder:1.22.5"
}
```

### Response

```json
{
    "message": "success"
}
```

## Delete Custom Image

> Only system administrators can call this endpoint. An image that is referenced by builds, tests, etc. cannot be deleted.


### Path Parameters

| Parameter Name | Type   | Description | Required |
| -------------- | ------ | ----------- | -------- |
| id             | string | Image ID    | Yes      |

### Response

```json
{
    "message": "success"
}
```
