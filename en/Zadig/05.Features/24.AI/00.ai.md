This article introduces AI model integration in Zadig. Supported providers include OpenAI, Azure, Azure AD, DeepSeek, SiliconFlow, Volcengine Ark, Aliyun Bailian, and Huawei Cloud ModelArts Studio.

After a model is integrated, it can be used in the following scenarios:

- [Zadig AI](/en/Zadig%20v5.1/ai/zadig-ai/): Use the current page context to troubleshoot failures, initialize projects and services, and diagnose environments and efficiency
- [Code Review](/en/Zadig%20v5.1/ai/code-review/): Review code changes, identify defects and risks, and write results back to the MR comment section
- [Release Specialist](/en/Zadig%20v5.1/ai/release-specialist/): Analyze release risk based on the change and release context, and output conclusions and recommendations
- [Audit Analysis](/en/Zadig%20v5.1/ai/audit-analysis/): Analyze commands in terminal sessions and provide a risk level and risk items
- [AI Task](/en/Zadig%20v5.1/project/workflow-jobs/#ai-task): Connect to an AI model and automatically execute intelligent tasks based on the prompt

## Add an AI Model

Go to `System Settings` → `Model Management`, select a provider, and fill in the model information.

![Add an AI Model](./_images/ai/ai_model_add-2.png)

Parameter description:

- `Model ID`: The identifier used to recognize the model in Zadig.
- `Provider`: Select the model provider.
- `Protocol`: OpenAI and Anthropic protocols are supported.
- `Model Name`: The model name on the provider side.
- `Address`: The API address of the model service.
- `API Key`: The key used to access the model service.

::: tip
Each capability selects its model in its own configuration. See [Zadig AI](/en/Zadig%20v5.1/ai/zadig-ai/), [Code Review](/en/Zadig%20v5.1/ai/code-review/), [Release Specialist](/en/Zadig%20v5.1/ai/release-specialist/), and [Audit Analysis](/en/Zadig%20v5.1/ai/audit-analysis/). An [AI Task](/en/Zadig%20v5.1/project/workflow-jobs/#ai-task) in a workflow selects its model in the task configuration.
:::

The following examples show how to obtain an API Key and address from common providers.

## DeepSeek

1. Complete registration on DeepSeek, generate [API Key](https://platform.deepseek.com/api_keys), create a new API Key, and copy it.

![deepseek](./_images/ai/ai_deepseek_1-2.png)

2. In Zadig, go to `System Settings` → `Model Management`, and add the DeepSeek AI model.

![deepseek](./_images/ai/ai_deepseek-2.png)

**Parameter Description:**

1. Provider: Select DeepSeek
2. Model Name: Enter the model provided by DeepSeek
3. Address: https://api.deepseek.com/v1
4. API Key: The API Key obtained in the previous step
