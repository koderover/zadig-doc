## Get Chart Template List

Returns the available Chart templates in the template library and the system variables supported by the templates.

**Request**

```
GET /openapi/templates/charts
```

**Permission**

This endpoint requires a valid API token.

**Response Description**

| Parameter Name     | Type                                | Description          |
| ------------------ | ----------------------------------- | -------------------- |
| `system_variables` | [][SystemVariable](#SystemVariable) | System variable list |
| `chart_templates`  | [][ChartTemplate](#ChartTemplate)   | Chart template list  |

<h4 id="SystemVariable">SystemVariable Parameter Description</h4>

| Parameter Name | Type   | Description   |
| -------------- | ------ | ------------- |
| `key`          | string | Variable name |
| `description`  | string | Description   |

<h4 id="ChartTemplate">ChartTemplate Parameter Description</h4>

| Parameter Name | Type   | Description          |
| -------------- | ------ | -------------------- |
| `name`         | string | Template name        |
| `codehost_id`  | int    | Code host ID         |
| `owner`        | string | Repository owner     |
| `namespace`    | string | Repository namespace |
| `repo`         | string | Repository name      |
| `path`         | string | Template path        |
| `branch`       | string | Branch name          |

**Response Example**

```json
{
    "system_variables": [
        {
            "key": "$T-Project$",
            "description": "Project name"
        }
    ],
    "chart_templates": [
        {
            "name": "demo",
            "codehost_id": 1,
            "owner": "koderover",
            "namespace": "charts",
            "repo": "demo-chart",
            "path": "charts/demo",
            "branch": "main"
        }
    ]
}
```
