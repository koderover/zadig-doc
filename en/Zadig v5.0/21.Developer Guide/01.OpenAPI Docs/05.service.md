## Get Service List

### Test Service

**Request**

```
GET /openapi/service/yaml/services?projectKey=<projectKey>
```
**Query Parameter Description**

| Parameter Name | Type   | Description   | Required |
| -------------- | ------ | ------------- | -------- |
| `projectKey`   | string | Project Key   | Yes      |

**Response Description**

| Parameter Name   | Type                        | Description                        |
| ---------------- | --------------------------- | ----------------------------------- |
| `service_name`   | string                      | Service name                       |
| `type`           | string                      | Service type, fixed value `k8s`     |
| `containers`     | [][Container](#Container-1) | List of service components          |

<h4 id="Container-1">Container Parameter Description</h4>

| Parameter Name | Type   | Description                |
| -------------- | ------ | -------------------------- |
| `name`         | string | Service component name     |
| `image`        | string | Service component image    |
| `image_name`   | string | Service component image name |

**Response Example**

::: details
```json
{
    "service": [
        {
            "service_name": "service-1",
            "type": "k8s",
            "containers": [
                {
                    "name": "myapp-1",
                    "image": "koderover.tencentcloudcr.com/koderover-demo/myapp-1:v0.1__linux_amd64",
                    "image_name": "myapp-1"
                }
            ]
        }
    ]
}
```

## Create New Service Using Template

### Test Service

**Request**

```

```

**Body Parameter Description**

| Parameter Name  | Description             | Type                  | Required |
| --------------- | ----------------------- | --------------------- | -------- |
| `service_name`  | Service name            | string                | Yes      |
| `project_key`   | Project key             | string                | Yes      |
| `template_name` | K8s Yaml Template Name  | string                | Yes      |
| `auto_sync`     | Auto sync switch         | bool                  | No       |
| `variable_yaml` | Template variable information | [][KeyVal](#KeyVal-5) | No       |

<h4 id="KeyVal-5">KeyVal Parameter Description</h4>

| Parameter Name | Description                                 | Type   | Required |
| -------------- | ------------------------------------------- | ------ | -------- |
| `key`          | Variable key value                           | string | Yes      |
| `value`        | Variable value, if there is nested value, use json format | any    | Yes      |

**Body Parameter Example**

Use template `microservice-template` to create service `service1` for project `demo`:

::: details
``` json
{
    "service_name": "service1",
    "project_key":"demo",
    "template_name": "microservice-template",
    "auto_sync": true,
    "variable_yaml": [
        {
            "key": "cpuLimit",
            "value": "100m"
        },
        {
            "key": "memoryLimit",
            "value": "100Mi"
        },
        {
            "key": "port",
            "value": "20221"
        }
    ]
}
```
:::

**Return**

```json
{
  "message": "success"
}
```

## Create a K8s YAML Service from a Code Repository

Reads YAML files or directories from an integrated code host and creates one or more K8s YAML services.

::: tip
Creating production services requires Zadig Professional Edition or above.
:::

**Request**

```
POST /openapi/service/loader/load/:codehostId
```

**Path Parameter Description**

| Parameter Name | Type | Description  | Required |
| -------------- | ---- | ------------ | -------- |
| `codehostId`   | int  | Code host ID | Yes      |

**Query Parameter Description**

| Parameter Name | Type   | Description                                                        | Required |
| -------------- | ------ | ------------------------------------------------------------------ | -------- |
| `repoName`     | string | Repository name; either `repoName` or `repoUUID` must be specified | No       |
| `repoUUID`     | string | Repository UUID; either `repoName` or `repoUUID` must be specified | No       |
| `branchName`   | string | Branch containing the service configuration                        | Yes      |
| `remoteName`   | string | Remote name for Gerrit; omit it for regular Git repositories       | No       |
| `repoOwner`    | string | Repository owner or organization                                   | Yes      |
| `namespace`    | string | Repository namespace; defaults to `repoOwner`                       | No       |
| `production`   | bool   | Whether to create a production service; defaults to `false`        | No       |

**Body Parameter Description**

| Parameter Name  | Type                            | Description       | Required |
| --------------- | ------------------------------- | ----------------- | -------- |
| `product_name`  | string                          | Project key       | Yes      |
| `service_paths` | [][ServicePath](#service-path)  | Service path list | Yes      |

<h4 id="service-path">ServicePath Parameter Description</h4>

| Parameter Name  | Type   | Description                                                        | Required |
| --------------- | ------ | ------------------------------------------------------------------ | -------- |
| `service_name`  | string | Service name                                                       | Yes      |
| `path`          | string | Relative path to a YAML file or directory in the repository       | Yes      |
| `is_dir`        | bool   | `true` for a directory or `false` for a single YAML file           | Yes      |

**Request Example**

```bash
curl -X POST \
  'https://yours.zadig.com/openapi/service/loader/load/1?repoName=demo&branchName=main&repoOwner=koderover&production=false' \
  -H 'Authorization: Bearer <your-token>' \
  -H 'Content-Type: application/json' \
  -d '{
    "product_name": "demo-project",
    "service_paths": [
      {
        "service_name": "backend",
        "path": "deploy/backend.yaml",
        "is_dir": false
      }
    ]
  }'
```

**Success Response**

```json
{
    "message": "success"
}
```

## Create a Helm Service

Creates Helm services from an integrated repository, a public repository, or an integrated Chart repository.

::: tip
Creating production services requires Zadig Professional Edition or above.
:::

**Request**

```
POST /openapi/service/helm/load?projectKey=<projectKey>
```

**Query Parameter Description**

| Parameter Name | Type   | Description | Required |
| -------------- | ------ | ----------- | -------- |
| `projectKey`   | string | Project key | Yes      |

**Body Parameter Description**

| Parameter Name | Type   | Description                                                                              | Required |
| -------------- | ------ | ---------------------------------------------------------------------------------------- | -------- |
| `source`       | string | Service source: `repo`, `gerrit`, `gitee`, `gitee-enterprise`, `publicRepo`, or `chartRepo` | Yes   |
| `name`         | string | Service name; for repository sources, the backend can read it from `Chart.yaml`          | No       |
| `createFrom`   | object | Source configuration; its structure depends on `source`                                  | Yes      |
| `production`   | bool   | Whether to create a production service; defaults to `false`                              | No       |

When `source` is `repo`, `gerrit`, `gitee`, or `gitee-enterprise`, `createFrom` has the following fields:

| Parameter Name | Type     | Description                                                | Required |
| -------------- | -------- | ---------------------------------------------------------- | -------- |
| `codehostID`   | int      | Code host ID                                               | Yes      |
| `owner`        | string   | Repository owner or organization                           | Yes      |
| `namespace`    | string   | Repository namespace; defaults to `owner`                  | No       |
| `repo`         | string   | Repository name                                            | Yes      |
| `branch`       | string   | Branch name                                                | Yes      |
| `paths`        | []string | Paths containing Charts; multiple services can be created  | Yes      |

When `source` is `publicRepo`, `createFrom` has the following fields:

| Parameter Name | Type     | Description                                                | Required |
| -------------- | -------- | ---------------------------------------------------------- | -------- |
| `repoLink`     | string   | Public repository URL                                      | Yes      |
| `paths`        | []string | Paths containing Charts; multiple services can be created  | Yes      |

When `source` is `chartRepo`, `createFrom` has the following fields:

| Parameter Name  | Type   | Description           | Required |
| --------------- | ------ | --------------------- | -------- |
| `chartRepoName` | string | Chart repository name | Yes      |
| `chartName`     | string | Chart name            | Yes      |
| `chartVersion`  | string | Chart version         | Yes      |

**Repository Request Example**

```json
{
    "source": "repo",
    "name": "",
    "createFrom": {
        "codehostID": 1,
        "owner": "koderover",
        "namespace": "koderover",
        "repo": "demo",
        "branch": "main",
        "paths": [
            "charts/backend"
        ]
    },
    "production": false
}
```

**Chart Repository Request Example**

```json
{
    "source": "chartRepo",
    "name": "",
    "createFrom": {
        "chartRepoName": "stable",
        "chartName": "nginx",
```
