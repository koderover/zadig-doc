## Get Zadig CLI Context

Returns the authenticated user and request ID for the current API token. System administrators also receive the Zadig edition, server version, and license information. Zadig CLI and other API clients can use this endpoint to verify the active identity and server capabilities before performing operations.

### Request

```
GET /openapi/system/cli/context
```

### Response Description

| Parameter Name       | Type     | Description                                      |
| -------------------- | -------- | ------------------------------------------------ |
| `user`               | object   | Authenticated user                               |
| `user.uid`           | string   | User UID                                         |
| `user.name`          | string   | User name                                        |
| `user.account`       | string   | User account                                     |
| `user.identity_type` | string   | User identity type                               |
| `edition`            | string   | Zadig edition; returned to system administrators |
| `license_status`     | string   | License status; returned to system administrators |
| `features`           | []string | Features enabled by the current license; returned to system administrators |
| `server_version`     | string   | Zadig server version; returned to system administrators |
| `request_id`         | string   | Request ID that can be used for troubleshooting  |

### Response Example

```json
{
    "user": {
        "uid": "45eb4cf9-3715-11f1-8976-42f9e9fb45c1",
        "name": "admin",
        "account": "admin",
        "identity_type": "system"
    },
    "edition": "enterprise",
    "license_status": "active",
    "features": [],
    "server_version": "5.0.0",
    "request_id": "7f64d2f5-47a7-4f61-9a38-2018037cab28"
}
```

Example response for a regular user:

```json
{
    "user": {
        "uid": "45eb4cf9-3715-11f1-8976-42f9e9fb45c1",
        "name": "developer",
        "account": "developer",
        "identity_type": "user"
    },
    "request_id": "7f64d2f5-47a7-4f61-9a38-2018037cab28"
}
```

## List System Operation Logs

### Request

```
GET /openapi/system/operation
```

### Query

| Parameter Name | Type   | Description                                                                                                         | Required |
| -------------- | ------ | ------------------------------------------------------------------------------------------------------------------- | -------- |
| searchType     | string | Search type, optional values:<br>`all`: all<br>`project`: project<br>`user`: user<br>`function`: function<br>`status`: status code | Yes      |
| projectKey     | string | Project key                                                                                                        | No       |
| username       | string | Username                                                                                                          | No       |
| function       | string | Function                                                                                                          | No       |
| status         | int    | Status code                                                                                                       | No       |
| perPage        | int    | Items per page                                                                                                    | Yes      |
| page           | int    | Page number                                                                                                       | Yes      |
