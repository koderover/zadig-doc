2026 年 11 月 19 日，Zadig 正式发布 v5.1.0 版本。

## 功能列表

**AI 智能体**
- 全新推出 Zadig AI 覆盖工作流报错分析、项目初始化等场景
- AI 环境巡检、AI 效能巡检集成至 Zadig AI 
- AI 代码审查规则支持同路径同级合并，跨级覆盖
- AI 代码审查支持以机器人身份回写评论
- 数据视图新增 AI 审查分析
- 数据视图新增 Zadig AI 分析
- AI 代码审查通知增加审查结果
- 飞书项目 DevOps+ 插件同步支持 AI 任务
- AI 发布专员适配 Apollo 新建 namespace 操作

**服务与环境**
- Helm 服务配置支持更新使用的模板
- Helm 项目服务详情支持 DaemonSet 资源
- CR 资源部署支持镜像字段为多段格式
- Helm Chart 实例化部署支持 Values 自动同步
- Helm 服务更新支持 UpgradeCRDs 选项

**工作流**
- 工作流动态变量支持多选
- 通用脚本执行任务支持按变量组执行多任务
- 构建配置中镜像构建步骤增加代理开关
- 执行工作流时 Helm Values 支持变量渲染
- APISIX 任务失败重试时跳过已成功的任务
- APISIX 执行页面展示资源 ID
- APISIX proto 发布增加 optional 兼容性提示
- APISIX 与 Apollo 配置变更执行时增加新增和修改标识
- Apollo 配置变更任务支持新建 Namespace
- 新增同一服务内 K8s 资源的部署顺序，保证部署稳定性

**发布计划**
- 发布计划支持自定义字段
- 重新编辑发布计划时对已完成的发布项给出提示
- 发布计划页面若干交互优化
- 发布计划中发布项负责人支持配置用户组，且仅发布负责人可修改
- 修复新建发布计划未设置审批修改权限仍可修改审批配置的问题
- 修复重新编辑发布计划新增部署服务时已选镜像被重置为默认值问题
- 修复多发布计划并发更新同一 Apollo 配置项相互覆盖问题

**系统集成与开放性**
- OpenAPI 支持含更新服务配置的工作流部署任务
- OpenAPI/CLI/MCP 支持项目更新和项目分组管理
- OpenAPI/CLI/MCP 支持业务目录管理
- OpenAPI/CLI/MCP 支持获取服务 Values、版本差异及更新操作
- OpenAPI/CLI/MCP 支持自定义镜像和构建模板管理
- OpenAPI/CLI/MCP 支持服务回滚
- CLI/MCP 支持 OAuth 方式鉴权
- CLI 支持使用 Helm 模板新建服务并加入测试环境
- CLI 支持使用模板批量导入 Values 文件创建服务
- CLI 查询工作流日志优化
- CLI 支持查看 Helm 环境服务详情
- MCP 支持查看工作流日志
- 飞书与飞书国际版账号系统支持配置用户名属性
- 主机管理支持指定项目范围
- 代理配置支持 HTTPS 与 SOCKS5 协议
- 集群调度工作流任务支持单独配置项目范围
- 集群管理支持阿里云集群的 RRSA 配置

**安全与合规**
- 构建 Pod 中屏蔽显示 Git 凭证
- 系统集成增加相应权限项
- 优化 zadig-review-agent 不读取敏感文件
- 容器调试与主机登录的操作命令纳入审计日志
- 系统操作日志优化并增强查询能力
- 修复鉴权绕过、未授权访问等安全漏洞，加强认证与权限校验
- 升级 Zadig 组件基础镜像以修复已知安全漏洞并提升稳定性
- 升级 Go、Docker、Helm 等核心组件及依赖版本，修复已知安全漏洞

**优化与修复**  
- 优化镜像回滚信息
- 优化仅导入服务的删除提示
- 优化环境选择与 Helm 服务搜索的交互体验
- 优化服务 Values 从 GitLab 导入时远程搜索分支
- 优化 Helm Values 编辑器，支持含换行符 config 的格式化渲染
- 优化 Helm 实例化部署服务的 Values 预览
- 优化环境更新 Helm Values 时「使用最新服务配置」选项的交互
- 优化 Deployment 状态检测逻辑
- 修复项目列表分页返回重复项目问题
- 修复历史日志量级过大时展示不全问题
- 修复 Helm 项目工作流部署任务运行报错问题
- 修复 Helm 部署提示 kube version 过低问题
- 修复 Helm 服务包含同名镜像无法同时更新问题
- 修复工作流变量偶发错乱问题
- 修复工作流页面添加服务或切换分支后旧 commit_id 残留问题
- 修复 APISIX proto 更新报 additional properties forbidden 问题
- 修复 APISIX 配置内容跨 OS 变更后对比不一致问题
- 修复代码库自签证书场景新建触发器报错问题
- 修复新建工作流强绑定内置模板保存报错问题
- 修复工作流变量从运行时输入切换到固定值后被清空问题
- 修复项目中添加用户组权限后看不到任何资源问题
- 修复 Helm 项目服务配置已不存在时更新环境触发 aslan 持续重启问题
- 修复 Helm 部署时子 Chart 未启用 CRD 被覆盖问题
- 修复主机项目构建可选镜像仓库但执行报错问题
- 修复 AWS 镜像仓库 AK/SK 修改后因缓存不生效问题
- 修复 Deployment pod ready 数展示有误问题
- 修复含镜像仓库单选变量的服务配置添加至环境后失效的问题
- 修复同 Namespace 多仓库凭证被 Zadig 配置覆盖问题
- 修复 Helm 配置删除后更新其他服务时被误删问题
- 修复服务组件多任务类型的通用任务必填变量校验问题
- 修复高并发镜像分发 unexpected EOF 问题
- 修复 Redis 异常后集群状态断联不会自动重连问题
- 修复更新集群调度策略触发 Agent 重建导致任务超时问题
- 若干修复及优化

### 版本升级过程

::: warning
若使用的 MongoDB 以 Replica Set 模式部署，请确认未使用 admin/local/config/test 等系统库作为 Zadig 的业务库；如有使用，请先手动迁移数据。


若当前系统版本 < v5.0.0，请先升级到 v5.0.0，具体升级步骤请参考 [v5.0.0 升级方式](/cn/Zadig%20v5.1/release-notes/v5.0.0/#版本升级过程)，然后再按照以下方式升级到 v5.1.0。
:::

::: tip
- 升级前请确认 Zadig AI 数据库。新增配置项 `connections.mysql.db.ai`，默认数据库名为 `zadig_ai`。若数据库账号没有自动创建数据库的权限，请先手动创建该数据库。
- 升级期间若出现 aslan 和 dind 均无法正常启动的情况，需要先将 dind 的副本数调整为0，解决两个组件启动时互相依赖的问题
:::

- [Helm 命令安装](/cn/Zadig%20v5.1/install/helm-deploy/#升级)
