本文介绍在 Zadig 系统上集成 AI 模型。支持接入 OpenAI、Azure、Azure AD、DeepSeek、SiliconFlow、火山方舟、阿里云百炼、华为云 ModelArts Studio 等多家模型提供商。

模型接入后可用于以下场景：

- [Zadig AI](/cn/Zadig%20v5.1/ai/zadig-ai/)：结合当前页面上下文，完成故障排查、项目与服务初始化，以及环境与效能诊断
- [代码审查](/cn/Zadig%20v5.1/ai/code-review/)：审查代码变更，识别缺陷与风险，结果可回写 MR 评论区
- [发布专员](/cn/Zadig%20v5.1/ai/release-specialist/)：结合变更与发布上下文进行风险分析，输出结论与建议
- [审计分析](/cn/Zadig%20v5.1/ai/audit-analysis/)：分析终端会话中的命令，给出风险等级和风险项
- [AI 任务](/cn/Zadig%20v5.1/project/workflow-jobs/#ai-任务)：对接 AI 模型，按提示词自动执行智能任务

## 新增 AI 模型

访问`系统设置` -> `模型管理`，选择提供商并填写模型信息。

![新增 AI 模型](./_images/ai/ai_model_add-2.png)

参数说明：

- `模型标识`：在 Zadig 中识别该模型的标识。
- `提供商`：选择模型提供商。
- `协议`： 支持 OpenAI 和 Anthropic 协议。
- `模型名称`：提供商侧的模型名称。
- `访问地址`：模型服务的 API 地址。
- `API Key`：访问模型服务的密钥。

::: tip
各能力在对应配置中选择模型，见 [Zadig AI](/cn/Zadig%20v5.1/ai/zadig-ai/)、[代码审查](/cn/Zadig%20v5.1/ai/code-review/)、[发布专员](/cn/Zadig%20v5.1/ai/release-specialist/) 和 [审计分析](/cn/Zadig%20v5.1/ai/audit-analysis/)。工作流中的 [AI 任务](/cn/Zadig%20v5.1/project/workflow-jobs/#ai-任务) 在任务配置里选择模型。
:::

以下以常见提供商为例，说明如何获取 API Key 和访问地址。

## DeepSeek

1. 在 DeepSeek 上完成注册，生成 [API Key](https://platform.deepseek.com/api_keys)，创建新的 API Key 并复制。

![deepseek](./_images/ai/ai_deepseek_1-2.png)

2. 在 Zadig 上，访问`系统设置` -> `模型管理`，添加 DeepSeek AI 模型。

![deepseek](./_images/ai/ai_deepseek-2.png)

**参数说明：**

1. 提供商：选择 DeepSeek
2. 模型名称：输入 DeepSeek 上提供的模型
3. 访问地址：https://api.deepseek.com/v1
4. API Key：上一步中获取的 API Key

## SiliconFlow

1. 在 SiliconFlow 上完成注册，生成 [API 密钥](https://cloud.siliconflow.cn/account/ak)，创建新的 API 密钥并复制。

![SiliconFlow](./_images/ai/ai_siliconflow_1-2.png)

2. 在 Zadig 上，访问`系统设置` -> `模型管理`，添加 AI 模型。

![SiliconFlow](./_images/ai/ai_siliconflow-2.png)

**参数说明：**

1. 提供商：选择 SiliconFlow
2. 模型名称：输入 SiliconFlow 上提供的模型
3. 访问地址：https://api.siliconflow.cn/v1
4. API Key：上一步中获取的 API 密钥

## 华为 ModelArts Studio

1. 在华为云 ModelArts Studio 上完成注册，生成 [API Key]((https://www.huaweicloud.com/product/modelarts/studio.html))，创建新的 API Key 并复制。

![华为云 ModelArts Studio](./_images/ai/ai_huawei_1-2.png)

2. 在 Zadig 上，访问`系统设置` -> `模型管理`，添加华为云 ModelArts Studio AI 模型。

![华为云 ModelArts Studio](./_images/ai/ai_huawei-2.png)

**参数说明：**

1. 提供商：选择华为云 ModelArts Studio
2. 模型名称：输入华为云 ModelArts Studio 上提供的模型，如 `deepseek-r1-250528`
3. 访问地址：https://api.modelarts-maas.com/v1/
4. API Key：上一步中获取的 API Key
