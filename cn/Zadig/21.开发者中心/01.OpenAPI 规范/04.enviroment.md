## 查看环境详情

### 测试环境
**请求**

```
GET /openapi/environments/<环境标识>?projectKey=<项目标识>
```

**Query 参数说明**

| 参数名       | 说明     | 类型   | 必填 |
| ------------ | -------- | ------ | ---- |
| `projectKey` | 项目标识 | string | 是   |

**返回示例**

::: details
``` json
{
    "project_key": "simple-demo",              # 项目标识
    "env_key": "dev",                          # 环境标识
    "update_by": "admin",                       # 环境更新者
    "update_time": 1689933256,                  # 最后一次更新时间，Unix 时间戳格式
    "cluster_id": "0123456789abcdef12345678",   # K8s 集群 ID
    "namespace": "simple-demo-env-dev",         # K8s 命名空间
    "registry_id": "630c7ad700430c131062e245",  # 镜像仓库 ID
    "global_variables": [                       # 全局变量列表
        {
            "key": "cpuLimit",                  # 变量的键
            "value": "1000m",                   # 变量的值
            "type": "string",                   # 变量的类型，包括 string、bool、enum、yaml 四种
            "options": [],                      # 变量的可选值，当 type 为 enum 时该字段有意义
            "desc": "CPU 资源限制",              # 变量的描述信息
            "related_services": ["service1"]    # 变量关联的服务
        }
    ],
    "services": [                               # 服务列表
        {
            "service_name": "service2",         # 服务名称
            "revision": 3,                      # 环境中服务使用的服务配置版本号
            "deploy_strategy": "deploy",        # 部署策略，包括 deploy、import、draft
            "containers": [                     # 服务组件信息
                {
                    "name": "myapp-1",          # 服务组件名称
                    "image": "koderover.tencentcloudcr.com/test/myapp-1:20230721164449-6-main", # 服务组件镜像
                    "image_name": "myapp-1"     # 服务组件镜像名称
                }
            ],
            "variable_kvs": [                   # 服务变量列表，为环境中已保存的值
                {
                    "key": "env1",
                    "value": "demo",
                    "type": "string",
                }
            ],
            "status": "running",               # 服务状态，包括 running(正在运行)、unstable(运行不稳定)、unstart(未开始)、failed(失败)、pending(挂起中)、unknown(未知)
            "type": "k8s"                      # 项目类型，恒定为 k8s
        }
    ],
    "status": "success"                        # 环境状态，包括 creating（创建中)、updating(更新中)、deleting(删除中)、succeeded(正常)、error(内部错误)、running(正在运行)、unstable(运行不稳定)、sleeping(睡眠中)、unknown(未知)
}
```
:::

## 查看 Helm 服务 Values 配置

::: tip
1. 适用于 Helm Chart 项目中的 Zadig 服务，不支持独立 Chart。
2. 返回的是环境中为该服务保存的覆盖配置，即 `values_yaml` 和 `override_kvs`，不包含 Chart 默认 Values。
3. 如需查看集群中实际部署的 Values，请使用下方“查看 Helm Release Values”接口。
4. 返回的 `revision` 可作为更新 Values 时的 `expected_revision`。
:::

**请求**

```
GET /openapi/environments/helm/<环境标识>/services/<服务名称>/values?projectKey=<项目标识>
```

**路径参数说明**

| 参数名     | 说明     | 类型   | 必填 |
| ---------- | -------- | ------ | ---- |
| `环境标识` | 环境标识 | string | 是   |
| `服务名称` | 服务名称 | string | 是   |

**Query 参数说明**

| 参数名       | 说明                                       | 类型   | 必填 |
| ------------ | ------------------------------------------ | ------ | ---- |
| `projectKey` | 项目标识                                   | string | 是   |
| `production` | 是否为生产环境，默认为 `false`             | bool   | 否   |
| `type`       | 服务类型，传入时只能为 `service`           | string | 否   |

**返回说明**

| 参数名         | 说明                                     | 类型                        |
| -------------- | ---------------------------------------- | --------------------------- |
| `release_name` | Helm Release 名称                        | string                      |
| `revision`     | 环境服务当前最新版本号                   | int                         |
| `values_yaml`  | 环境中保存的覆盖 Values YAML             | string                      |
| `override_kvs` | 环境中保存的覆盖 KV 列表                 | [][OverrideKV](#OverrideKV) |

**返回示例**

::: details
```json
{
    "release_name": "demo-dev-service1",
    "revision": 3,
    "values_yaml": "replicaCount: 2\nimage:\n  tag: 20250711170816-5-main\n",
    "override_kvs": [
        {
            "key": "resources.limits.cpu",
            "value": "200m"
        }
    ]
}
```
:::

## 查看 Helm Release Values

::: tip
1. 适用于 Helm Chart 项目中的 Zadig 服务，不支持独立 Chart。
2. 返回的是集群中该服务对应 Helm Release 实际部署的 Values，即合并后真正生效的结果。
:::

**请求**

```
GET /openapi/environments/helm/<环境标识>/services/<服务名称>/release/values?projectKey=<项目标识>
```

**路径参数说明**

| 参数名     | 说明     | 类型   | 必填 |
| ---------- | -------- | ------ | ---- |
| `环境标识` | 环境标识 | string | 是   |

## 更新 Helm 服务 Values

::: tip
1. 适用于 Helm Chart 项目中的 Zadig 服务，不支持独立 Chart。
2. 接口保存配置后在后台异步部署，返回成功不代表部署完成，请查询服务状态确认结果。
3. `expected_revision` 与当前版本号不一致，或环境正在更新中时，返回 409。
:::

**请求**

```
PUT /openapi/environments/helm/<环境标识>/services/<服务名称>/values?projectKey=<项目标识>
```

**路径参数说明**

| 参数名     | 说明     | 类型   | 必填 |
| ---------- | -------- | ------ | ---- |
| `环境标识` | 环境标识 | string | 是   |
| `服务名称` | 服务名称 | string | 是   |

**Query 参数说明**

| 参数名       | 说明                           | 类型   | 必填 |
| ------------ | ------------------------------ | ------ | ---- |
| `projectKey` | 项目标识                       | string | 是   |
| `production` | 是否为生产环境，默认为 `false` | bool   | 否   |

**Body 参数说明**

| 参数名                    | 说明                                                                                                                                                      | 类型                        | 必填 |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- | ---- |
| `expected_revision`       | 期望的当前版本号，取自“查看 Helm 服务 Values 配置”接口返回的 `revision`，需大于等于 0                                                                     | int                         | 是   |
| `values_yaml`             | 新的覆盖 Values YAML；开启自动同步时不可使用；不能与 `sync_values_from_source` 同时使用                                                                  | string                      | 否   |
| `override_kvs`            | 新的覆盖 KV 列表，传入后整体替换原列表；key 不能为空或重复，value 只支持 string、number、bool                                                            | [][OverrideKV](#OverrideKV) | 否   |
| `sync_values_from_source` | 是否从已配置的 Git Values 来源重新拉取 Values，需先配置 Values 来源                                                                                       | bool                        | 否   |
| `update_service_revision` | 是否同时更新到最新的服务配置版本                                                                                                                          | bool                        | 否   |
| `value_merge_strategy`    | `values_yaml` 的合并方式，默认为 `override`：<br>`override`：用 `values_yaml` 整体替换环境中的覆盖 Values<br>`reuse-values`：将 `values_yaml` 合并到环境现有覆盖 Values，需同时传入 `values_yaml` | string                      | 否   |
| `upgrade_crd`             | 是否升级 Chart 中的 CRD，默认为 `true`                                                                                                                   | bool                        | 否   |

> `values_yaml`、`override_kvs`、`sync_values_from_source`、`update_service_revision` 至少传入一项。

**Body 参数示例**

::: details
```json
{
    "expected_revision": 3,
    "values_yaml": "replicaCount: 3\n",
    "override_kvs": [
        {
            "key": "resources.limits.cpu",
            "value": "200m"
        }
    ],
    "value_merge_strategy": "reuse-values",
    "upgrade_crd": true
}
```
:::

**返回示例**

```json
{
    "message": "success"
}
```

## 服务版本

::: tip
1. 环境中的服务每次部署都会生成一个版本，可通过以下接口查看、对比和回滚。


| 参数名       | 说明          | 类型   | 必填 |
| ------------ | ------------- | ------ | ---- |
| `projectKey` | 项目标识      | string | 是   |
