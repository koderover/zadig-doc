## 获取 Chart 模板列表

获取模板库中可用的 Chart 模板以及模板支持的系统变量。

**请求**

```
GET /openapi/templates/charts
```

**权限说明**

调用者需要有模板库的查看权限。

**返回说明**

| 参数名             | 类型                                | 描述           |
| ------------------ | ----------------------------------- | -------------- |
| `system_variables` | [][SystemVariable](#SystemVariable) | 系统变量列表，按 `key` 排序 |
| `chart_templates`  | [][ChartTemplate](#ChartTemplate)   | Chart 模板列表 |

<h4 id="SystemVariable">SystemVariable 参数说明</h4>

| 参数名        | 类型   | 描述     |
| ------------- | ------ | -------- |
| `key`         | string | 变量名称 |
| `description` | string | 变量描述，为空时不返回 |

<h4 id="ChartTemplate">ChartTemplate 参数说明</h4>

| 参数名        | 类型   | 描述                 |
| ------------- | ------ | -------------------- |
| `name`        | string | 模板名称             |
| `codehost_id` | int    | 代码源 ID            |
| `owner`       | string | 代码库所属用户或组织 |
| `namespace`   | string | 代码库命名空间       |
| `repo`        | string | 代码库名称           |
| `path`        | string | 模板路径             |
| `branch`      | string | 分支名称             |

**返回示例**

```json
{
    "system_variables": [
        {
            "key": "$T-Project$",
            "description": "项目名称"
        }
    ],
    "chart_templates": [
        {
            "name": "demo",
            "codehost_id": 1,
            "owner": "koderover",
            "namespace": "charts",
            "repo": "demo-chart",
            "path": "charts/demo",
            "branch": "main"
        }
    ]
}
```

## 获取 K8s YAML 模板列表

**请求**

```
GET /openapi/templates/yaml?pageNum=<当前页数>&pageSize=<当前页显示条数>
```

**权限说明**

调用者需要有模板库的查看权限。没有该权限时，需要传入 `projectKey`，并且是该项目的管理员，或有该项目的服务（含生产服务）新建权限。

**Query 参数说明**

| 参数名       | 说明                                           | 类型   | 必填 |
| ------------ | ---------------------------------------------- | ------ | ---- |
| `projectKey` | 项目标识，没有模板库查看权限时必填             | string | 否   |
| `pageNum`    | 分页当前页数，必须大于 0，默认值：1            | int    | 否   |
| `pageSize`   | 分页每页显示数量，必须大于 0，默认值：20       | int    | 否   |

**返回说明**

| 参数名           | 类型                            | 描述          |
| ---------------- | ------------------------------- | ------------- |
| `total`          | int                             | 模板总数      |
| `yaml_templates` | [][YamlTemplate](#YamlTemplate) | YAML 模板列表 |

<h4 id="YamlTemplate">YamlTemplate 参数说明</h4>

| 参数名          | 类型                      | 描述                                         |
| --------------- | ------------------------- | -------------------------------------------- |
| `id`            | string                    | 模板 ID                                      |
| `name`          | string                    | 模板名称                                     |
| `source`        | string                    | 模板来源，从代码库同步的模板为代码源类型     |
| `codehostID`    | int                       | 代码源 ID                                    |
| `repo_owner`    | string                    | 代码库所属用户或组织                         |
| `namespace`     | string                    | 代码库命名空间                               |
| `repo`          | string                    | 代码库名称                                   |
| `path`          | string                    | 模板文件路径                                 |
| `branch`        | string                    | 分支名称                                     |
| `remote_name`   | string                    | Remote 名称                                  |
| `load_from_dir` | bool                      | 是否从目录加载                               |
| `commit`        | [Commit](#Commit)         | 同步时的提交信息                             |

> 除 `id`、`name` 外的字段为空时不返回。

<h4 id="Commit">Commit 参数说明</h4>

| 参数名    | 类型   | 描述       |
| --------- | ------ | ---------- |
| `sha`     | string | 提交 SHA   |
| `message` | string | 提交信息   |

**返回示例**

```json
{
    "total": 2,
    "yaml_templates": [
        {
            "id": "6650a7e1b2c3d4e5f6a7b8c9",
            "name": "nginx-deployment"
        },
        {
            "id": "6650a7e1b2c3d4e5f6a7b8ca",
            "name": "service-template",
            "source": "gitlab",
            "codehostID": 1,
            "repo_owner": "koderover",
            "namespace": "koderover",
            "repo": "k8s-templates",
            "path": "templates/service.yaml",
            "branch": "main",
            "remote_name": "origin",
            "commit": {
                "sha": "3f2a1b9c8d7e6f5a4b3c2d1e0f9a8b7c6d5e4f3a",
                "message": "update service template"
            }
        }
    ]
}
```

## 获取 K8s YAML 模板详情

**请求**

```
GET /openapi/templates/yaml/:id
```

**权限说明**

同 [获取 K8s YAML 模板列表](#获取-k8s-yaml-模板列表)。

**路径参数说明**

| 参数名 | 说明    | 类型   | 必填 |
| ------ | ------- | ------ | ---- |
| `id`   | 模板 ID | string | 是   |

**Query 参数说明**

| 参数名       | 说明                               | 类型   | 必填 |
| ------------ | ---------------------------------- | ------ | ---- |
| `projectKey` | 项目标识，没有模板库查看权限时必填 | string | 否   |

**返回说明**

| 参数名                 | 类型                                      | 描述                         |
| ---------------------- | ----------------------------------------- | ---------------------------- |
| `id`                   | string                                    | 模板 ID                      |
| `name`                 | string                                    | 模板名称                     |
| `content`              | string                                    | 模板内容                     |
| `variable_yaml`        | string                                    | 模板变量，YAML 格式          |
| `service_variable_kvs` | [][ServiceVariableKV](#ServiceVariableKV) | 模板变量定义列表             |
| `source`               | string                                    | 模板来源                     |
| `codehostID`           | int                                       | 代码源 ID                    |
| `repo_owner`           | string                                    | 代码库所属用户或组织         |
| `namespace`            | string                                    | 代码库命名空间               |
| `repo_name`            | string                                    | 代码库名称                   |
| `path`                 | string                                    | 模板文件路径                 |
| `branch_name`          | string                                    | 分支名称                     |
| `remote_name`          | string                                    | Remote 名称                  |
| `load_from_dir`        | bool                                      | 是否从目录加载               |
| `commit`               | [Commit](#Commit)                         | 同步时的提交信息             |

> `source` 及之后的字段为空时不返回。

<h4 id="ServiceVariableKV">ServiceVariableKV 参数说明</h4>

| 参数名    | 类型     | 描述                                         |
| --------- | -------- | -------------------------------------------- |
| `key`     | string   | 变量名称                                     |
| `value`   | any      | 变量默认值                                   |
| `type`    | string   | 变量类型，支持 `string`、`enum`、`bool`、`yaml` |
| `options` | []string | 可选值列表，`type` 为 `enum` 时使用          |
| `desc`    | string   | 变量描述                                     |

**返回示例**

```json
{
    "id": "6650a7e1b2c3d4e5f6a7b8c9",
    "name": "nginx-deployment",
    "content": "apiVersion: apps/v1\nkind: Deployment\nmetadata:\n  name: {{.Name}}\nspec:\n  replicas: {{.Replicas}}\n  template:\n    spec:\n      containers:\n        - name: {{.Name}}\n          image: nginx:1.25\n",
    "variable_yaml": "Name: nginx\nReplicas: 1\n",
    "service_variable_kvs": [
        {
            "key": "Name",
            "value": "nginx",
            "type": "string",
            "options": [],
            "desc": "服务名称"
        },
        {
            "key": "Replicas",
            "value": "1",
            "type": "enum",
            "options": ["1", "2", "3"],
            "desc": "副本数"
        }
    ]
}
```

## 获取构建模板列表

**请求**

```
GET /openapi/templates/builds?pageNum=<当前页数>&pageSize=<当前页显示条数>
```

**权限说明**

调用者需要有模板库的查看权限。

**Query 参数说明**

| 参数名     | 说明                                     | 类型 | 必填 |
| ---------- | ---------------------------------------- | ---- | ---- |
| `pageNum`  | 分页当前页数，必须大于 0，默认值：1      | int  | 否   |
| `pageSize` | 分页每页显示数量，必须大于 0，默认值：20 | int  | 否   |

**返回说明**

| 参数名            | 类型                                        | 描述         |
| ----------------- | ------------------------------------------- | ------------ |
| `total`           | int                                         | 构建模板总数 |
| `build_templates` | [][BuildTemplateBrief](#BuildTemplateBrief) | 构建模板列表 |

<h4 id="BuildTemplateBrief">BuildTemplateBrief 参数说明</h4>

| 参数名           | 类型   | 描述                                               |
| ---------------- | ------ | -------------------------------------------------- |
| `id`             | string | 构建模板 ID                                        |
| `name`           | string | 构建模板名称                                       |
| `infrastructure` | string | 基础设施，kubernetes 为 Kubernetes 集群，vm 为主机 |
| `update_time`    | int    | 更新时间，秒级时间戳                               |
| `update_by`      | string | 更新者                                             |

**返回示例**

```json
{
    "total": 2,
    "build_templates": [
        {
            "id": "6650b1c2d3e4f5a6b7c8d9e0",
            "name": "go-build",
            "infrastructure": "kubernetes",
            "update_time": 1755500000,
            "update_by": "admin"
        },
        {
            "id": "6650b1c2d3e4f5a6b7c8d9e1",
            "name": "windows-build",
            "infrastructure": "vm",
            "update_time": 1755400000,
            "update_by": "admin"
        }
    ]
}
```

## 新建构建模板

**请求**

```
POST /openapi/templates/builds
```

**权限说明**

调用者需要有模板库的新建权限。

**body 参数说明**

| 参数名              | 说明                                                                             | 类型                                                | 必填 |
| ------------------- | -------------------------------------------------------------------------------- | --------------------------------------------------- | ---- |
| `name`              | 构建模板名称                                                                     | string                                              | 是   |
| `infrastructure`    | 基础设施，kubernetes 为 Kubernetes 集群，vm 为主机                               | string                                              | 是   |
| `vm_labels`         | 主机标签，`infrastructure` 为 vm 时必填                                          | []string                                            | 否   |
| `build_os`          | 构建镜像名称，即系统设置中构建镜像的名称，如 `ubuntu 20.04` 或自定义镜像的名称   | string                                              | 是   |
| `installs`          | 依赖的软件包                                                                     | [][Install](#Install)                               | 否   |
| `parameters`        | 自定义变量                                                                       | [][BuildTemplateParameter](#BuildTemplateParameter) | 否   |
| `script_type`       | 脚本类型，支持 shell、batch_file、powershell                                     | string                                              | 是   |
| `build_script`      | 构建脚本                                                                         | string                                              | 是   |
| `docker_build_step` | 镜像构建步骤                                                                     | [DockerBuildStep](#BuildTemplateDockerBuildStep)    | 否   |
| `advanced_settings` | 高级设置，不传时使用默认配置                                                     | [AdvancedSettings](#BuildTemplateAdvancedSettings)  | 否   |

> 不传 `advanced_settings` 时，使用默认配置：超时时间 60，资源规格为 CPU 1000m/4000m、内存 1024Mi/8192Mi，基础设施为 kubernetes 时使用本地集群及其默认调度策略。

<h4 id="Install">Install 参数说明</h4>

| 参数名    | 说明       | 类型   | 必填 |
| --------- | ---------- | ------ | ---- |
| `name`    | 软件包名称 | string | 是   |
| `version` | 软件包版本 | string | 是   |

<h4 id="BuildTemplateParameter">BuildTemplateParameter 参数说明</h4>

| 参数名          | 说明                                          | 类型     | 必填 |
| --------------- | --------------------------------------------- | -------- | ---- |
| `key`           | 变量的键值                                    | string   | 是   |
| `type`          | 变量的类型，支持 string、choice、multi-select | string   | 是   |
| `default_value` | 变量的默认值，不能为空                        | string   | 是   |
| `choice_option` | 变量的可选值列表                              | []string | 否   |
| `choice_value`  | 变量的多选值列表，`type` 为 multi-select 时使用 | []string | 否   |
| `is_credential` | 是否为敏感信息                                | bool     | 否   |
| `description`   | 变量的描述                                    | string   | 否   |
| `required`      | 是否必填                                      | bool     | 否   |

<h4 id="BuildTemplateDockerBuildStep">DockerBuildStep 参数说明</h4>

| 参数名                 | 说明                                                                 | 类型   | 必填 |
| ---------------------- | -------------------------------------------------------------------- | ------ | ---- |
| `dockerfile_source`    | Dockerfile 源，local 为代码库，template 为模板库                     | string | 是   |
| `build_context_dir`    | 构建上下文目录                                                       | string | 是   |
| `dockerfile_directory` | Dockerfile 的绝对路径，`dockerfile_source` 为 local 时必填           | string | 否   |
| `template_name`        | Dockerfile 模板名称，`dockerfile_source` 为 template 时必填          | string | 否   |
| `build_args`           | 构建参数                                                             | string | 否   |
| `enable_proxy`         | 是否在镜像构建时注入代理参数，需同时开启系统代理                     | bool   | 否   |
| `enable_buildkit`      | 是否启用 Buildkit                                                    | bool   | 否   |
| `platforms`            | Buildkit 构建平台，如 `linux/amd64`，`enable_buildkit` 为 true 时必填 | string | 否   |

<h4 id="BuildTemplateAdvancedSettings">AdvancedSettings 参数说明</h4>

| 参数名                   | 说明                                                     | 类型                                                | 必填 |
| ------------------------ | -------------------------------------------------------- | --------------------------------------------------- | ---- |
| `timeout`                | 构建超时时间，必须大于 0                                 | int                                                 | 是   |
| `cluster_name`           | 集群名称，`infrastructure` 为 kubernetes 时必填          | string                                              | 否   |
| `strategy_name`          | 调度策略名称，需为所选集群中已有的调度策略               | string                                              | 否   |
| `resource_spec`          | 资源规格                                                 | [ResourceSpec](#BuildTemplateResourceSpec)          | 否   |
| `cache_setting`          | 缓存配置                                                 | [CacheSetting](#BuildTemplateCacheSetting)          | 否   |
| `storages`               | 存储配置                                                 | [StorageSetting](#BuildTemplateStorageSetting)      | 否   |
| `use_host_docker_daemon` | 是否使用宿主机 docker daemon                             | bool                                                | 否   |
| `privileged_mode`        | 是否启用特权模式                                         | bool                                                | 否   |
| `custom_annotations`     | 自定义注解                                               | [][KeyValue](#BuildTemplateKeyValue)                | 否   |
| `custom_labels`          | 自定义标签                                               | [][KeyValue](#BuildTemplateKeyValue)                | 否   |
| `outputs`                | 输出变量名称列表                                         | []string                                            | 否   |

<h4 id="BuildTemplateResourceSpec">ResourceSpec 参数说明</h4>

| 参数名         | 说明                         | 类型   | 必填 |
| -------------- | ---------------------------- | ------ | ---- |
| `cpu_req`      | CPU 请求，单位 m             | int    | 否   |
| `cpu_limit`    | CPU 限制，单位 m             | int    | 否   |
| `memory_req`   | 内存请求，单位 Mi            | int    | 否   |
| `memory_limit` | 内存限制，单位 Mi            | int    | 否   |
| `gpu_limit`    | GPU 限制，如 `nvidia.com/gpu: 1` | string | 否   |

> 资源值不能为负数，请求值不能大于限制值。

<h4 id="BuildTemplateCacheSetting">CacheSetting 参数说明</h4>

| 参数名      | 说明                                                       | 类型   | 必填 |
| ----------- | ---------------------------------------------------------- | ------ | ---- |
| `enabled`   | 是否启用缓存                                               | bool   | 否   |
| `cache_dir` | 自定义缓存目录，启用缓存且为空时使用工作空间作为缓存目录 | string | 否   |

<h4 id="BuildTemplateStorageSetting">StorageSetting 参数说明</h4>

| 参数名                | 说明         | 类型                                                  | 必填 |
| --------------------- | ------------ | ----------------------------------------------------- | ---- |
| `enabled`             | 是否启用存储 | bool                                                  | 否   |
| `storages_properties` | 存储属性列表 | [][StoragesProperty](#BuildTemplateStoragesProperty) | 否   |

<h4 id="BuildTemplateStoragesProperty">StoragesProperty 参数说明</h4>

| 参数名                | 说明                                                                                                           | 类型   | 必填 |
| --------------------- | -------------------------------------------------------------------------------------------------------------- | ------ | ---- |
| `provision_type`      | 存储类型，dynamic 为动态资源，static 为已有存储                                                                | string | 是   |
| `mount_path`          | 挂载路径                                                                                                       | string | 是   |
| `storage_class`       | 存储类名称，provision_type 为 dynamic 时必填                                                                   | string | 否   |
| `storage_size_in_gib` | 存储大小，单位 GiB，provision_type 为 dynamic 时必填且大于 0                                                   | int    | 否   |
| `pvc`                 | PVC 名称，provision_type 为 static 时必填                                                                      | string | 否   |
| `access_mode`         | 访问模式，如不设置则默认为 ReadWriteMany，支持 ReadWriteOnce、 ReadOnlyMany、 ReadWriteMany、 ReadWriteOncePod | string | 否   |
| `subpath`             | 存储卷子路径                                                                                                   | string | 否   |
| `is_temporary`        | 是否为临时存储                                                                                                 | bool   | 否   |

> 仅在 `enabled` 为 true 时校验存储属性。

<h4 id="BuildTemplateKeyValue">KeyValue 参数说明</h4>

| 参数名  | 说明 | 类型   | 必填 |
| ------- | ---- | ------ | ---- |
| `key`   | 键   | string | 是   |
| `value` | 值   | string | 是   |

**body 参数示例**

```json
{
    "name": "go-build",
    "infrastructure": "kubernetes",
    "build_os": "ubuntu 20.04",
    "installs": [
        {
            "name": "go",
            "version": "1.22.5"
        }
    ],
    "parameters": [
        {
            "key": "GOPROXY",
            "type": "string",
            "default_value": "https://goproxy.cn",
            "is_credential": false,
            "description": "Go 代理地址",
            "required": false
        },
```

## 更新构建模板

> 更新为全量覆盖，未传的字段会被清空或恢复默认值。不传 `advanced_settings` 时，高级设置会恢复为默认配置。

**请求**

```
PUT /openapi/templates/builds/:id
```

**权限说明**

调用者需要有模板库的编辑权限。

**路径参数说明**

| 参数名 | 说明        | 类型   | 必填 |
| ------ | ----------- | ------ | ---- |
| `id`   | 构建模板 ID | string | 是   |

**body 参数说明**

同 [新建构建模板](#新建构建模板) 的 body 参数。

**body 参数示例**

```json
{
    "name": "windows-build",
    "infrastructure": "vm",
    "vm_labels": ["windows"],
    "build_os": "ubuntu 20.04",
    "installs": [],
    "parameters": [],
    "script_type": "powershell",
    "build_script": "cd $env:REPONAME_0\n.\\build.ps1",
    "advanced_settings": {
        "timeout": 30,
        "resource_spec": {
            "cpu_req": 1000,
            "cpu_limit": 2000,
            "memory_req": 1024,
            "memory_limit": 2048
        },
        "cache_setting": {
            "enabled": false,
            "cache_dir": ""
        }
    }
}
```

**返回说明**

```json
{
  "message": "success"
}
```

## 删除构建模板

> 构建模板已被构建引用时，无法删除。

**请求**

```
DELETE /openapi/templates/builds/:id
```

**权限说明**

调用者需要有模板库的删除权限。

**路径参数说明**

| 参数名 | 说明        | 类型   | 必填 |
| ------ | ----------- | ------ | ---- |
| `id`   | 构建模板 ID | string | 是   |

**返回说明**

```json
{
  "message": "success"
}
```
