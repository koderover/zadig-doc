## 列出系统操作日志

### 请求

```
GET /openapi/system/operation
```

### Query

| 参数名     | 类型   | 描述                                                                                                         | 必填 |
| ---------- | ------ | ------------------------------------------------------------------------------------------------------------ | ---- |
| searchType | string | 搜索类型，可选值：<br>`all`：全部<br>`project`：项目<br>`user`：用户<br>`function`：功能<br>`status`：状态码 | 是   | 是 |
| projectKey | string | 项目标识                                                                                                     | 否   |
| username   | string | 用户名                                                                                                       | 否   |
| function   | string | 功能                                                                                                         | 否   |
| status     | int    | 状态码                                                                                                       | 否   |
| perPage    | int    | 每页数量                                                                                                     | 是   |
| page       | int    | 页码                                                                                                         | 是   |

### 返回

            "username": "admin",                  // 用户名

## 获取自定义镜像列表

> 仅系统管理员可调用。

### 请求

```
GET /openapi/system/custom_image
```

### 返回

| 参数名          | 类型                            | 描述           |
| --------------- | ------------------------------- | -------------- |
| `custom_images` | [][CustomImage](#CustomImage)   | 自定义镜像列表 |

<h4 id="CustomImage">CustomImage 参数说明</h4>

| 参数名        | 类型   | 描述                                       |
| ------------- | ------ | ------------------------------------------ |
| `id`          | string | 镜像 ID                                    |
| `label`       | string | 镜像名称，构建、测试等配置中使用该名称选择镜像 |
| `value`       | string | 镜像地址                                   |
| `create_time` | int    | 创建时间，秒级时间戳                       |
| `update_time` | int    | 更新时间，秒级时间戳                       |
| `update_by`   | string | 更新者                                     |

```json
{
    "custom_images": [
        {
            "id": "6651a2b3c4d5e6f7a8b9c0d1",
            "label": "go-1.22",
            "value": "koderover.tencentcloudcr.com/test/go-builder:1.22",
            "create_time": 1755300000,
            "update_time": 1755500000,
            "update_by": "admin"
        }
    ]
}
```

## 获取自定义镜像详情

> 仅系统管理员可调用。

### 请求

```
GET /openapi/system/custom_image/:id
```

### 路径参数

| 参数名 | 类型   | 描述    | 必填 |
| ------ | ------ | ------- | ---- |
| id     | string | 镜像 ID | 是   |

### 返回

字段说明见 [CustomImage 参数说明](#CustomImage)。

```json
{
    "id": "6651a2b3c4d5e6f7a8b9c0d1",
    "label": "go-1.22",
    "value": "koderover.tencentcloudcr.com/test/go-builder:1.22",
    "create_time": 1755300000,
    "update_time": 1755500000,
    "update_by": "admin"
}
```

## 新建自定义镜像

> 仅系统管理员可调用。镜像地址不能与已有镜像重复。

### 请求

```
POST /openapi/system/custom_image
```

### Body

| 参数名 | 类型   | 描述     | 必填 |
| ------ | ------ | -------- | ---- |
| label  | string | 镜像名称 | 是   |
| value  | string | 镜像地址 | 是   |

```json
{
    "label": "go-1.22",
    "value": "koderover.tencentcloudcr.com/test/go-builder:1.22"
}
```

### 返回

```json
{
    "message": "success"
}
```

## 更新自定义镜像

> 仅系统管理员可调用。镜像地址不能与其他镜像重复。

### 请求

```
PUT /openapi/system/custom_image/:id
```

### 路径参数

| 参数名 | 类型   | 描述    | 必填 |
| ------ | ------ | ------- | ---- |
| id     | string | 镜像 ID | 是   |

### Body

| 参数名 | 类型   | 描述     | 必填 |
| ------ | ------ | -------- | ---- |
| label  | string | 镜像名称 | 是   |
| value  | string | 镜像地址 | 是   |

```json
{
    "label": "go-1.22",
    "value": "koderover.tencentcloudcr.com/test/go-builder:1.22.5"
}
```

### 返回

```json
{
    "message": "success"
}
```

> 仅系统管理员可调用。镜像已被构建、测试等引用时，无法删除。

### 请求

```
DELETE /openapi/system/custom_image/:id
```

### 路径参数

| 参数名 | 类型   | 描述    | 必填 |
| ------ | ------ | ------- | ---- |
| id     | string | 镜像 ID | 是   |

### 返回

```json
{
    "message": "success"
}
```
