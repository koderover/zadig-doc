## 查询业务列表

**请求**

```text
POST /openapi/application/applications/search
```

**Body 参数说明**

| 参数名 | 类型 | 描述 | 必填 |
| --- | --- | --- | --- |
| `page` | integer | 页码，从 1 开始；不传或小于等于 0 时为 1 | 否 |
| `page_size` | integer | 每页数量；不传或小于等于 0 时为 20 | 否 |
| `query` | string | 按业务名称或标识进行不区分大小写的模糊搜索 | 否 |
| `filters` | object[] | 过滤条件，多个条件之间为“且”关系；与 `query` 同时生效 | 否 |
| `sort_by` | string | 排序字段，默认 `update_time`；可选字段同过滤字段 | 否 |
| `sort_order` | string | `asc` 升序或 `desc` 降序，默认 `asc` | 否 |

**filters 参数说明**

| 参数名 | 类型 | 描述 | 必填 |
| --- | --- | --- | --- |
| `field` | string | 过滤字段，见下表 | 是 |
| `verb` | string | 操作符，需与字段类型对应 | 是 |
| `value` | string / number / boolean / string[] | 过滤值；使用 `is_empty`、`is_not_empty` 时不传，其他操作符均必填 | 取决于操作符 |

| 过滤字段 | 值类型 |
| --- | --- |
| `name`、`key`、`project`、`type`、`owner`、`description`、`testing_service_name`、`production_service_name` | string |
| `repository.codehost_id` | number，代码源 ID |
| `create_time`、`update_time` | number，Unix 时间戳，单位为秒 |
| `custom_fields.<字段标识>` | 取决于自定义字段类型 |

| 字段类型 | 支持的操作符 | value 类型 |
| --- | --- | --- |
| 文本、单选、链接、用户、用户组、项目 | `=`、`!=`、`begins_with`、`not_begins_with`、`ends_with`、`not_ends_with`、`contains`、`not_contains` | string |
| 文本、单选、链接、用户、用户组、项目 | `has_any_of`，匹配任意一个值 | string[] |
| 数字、日期时间 | `=`、`!=`、`<`、`<=`、`>`、`>=` | number |
| 布尔 | `is` | boolean |
| 多选 | `contains`、`not_contains`，包含或不包含某个选项 | string |
| 多选 | `has_any_of`，包含任意一个选项 | string[] |
| 多选 | `is_empty`、`is_not_empty` | 无需填写 |

字符串匹配不区分大小写。使用字符串的否定条件或多选的 `not_contains` 过滤时，仅返回该字段存在、值非 `null` 且满足过滤条件的业务。

**请求示例**

以下示例假定已创建单选字段 `priority`，并配置选项 `P0`、`P1`。

```json
{
  "page": 1,
  "page_size": 20,
  "query": "order",
  "filters": [
    {"field": "project", "verb": "=", "value": "shop"},
    {"field": "custom_fields.priority", "verb": "=", "value": "P0"}
  ],
  "sort_by": "update_time",
  "sort_order": "desc"
}
```

**返回参数说明**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| `items` | object[] | 当前页业务列表，业务对象说明见“查询业务详情” |
| `page` | integer | 当前页码 |
| `page_size` | integer | 每页数量 |
| `total` | integer | 符合条件的业务总数 |

**返回示例**

仅展示业务使用所需的字段。

```json
{
  "items": [
    {
      "id": "6aff00000000000000000001",
      "name": "订单服务",
      "key": "order-service",
      "project": "shop",
      "type": "服务",
      "owner": "",
      "description": "订单处理服务",
      "repository": {
        "codehost_id": 1,
        "repo_owner": "shop-team",
        "repo_name": "order-service"
      },
      "testing_service_name": "order-service",
      "production_service_name": "",
      "custom_fields": {"priority": "P0"},
      "create_time": 1795132800,
      "update_time": 1795132800
    }
  ],
  "page": 1,
  "page_size": 20,
  "total": 1
}
```

## 查询业务详情

**请求**

```text
GET /openapi/application/applications/:id
```

路径参数 `id` 为业务 ID，从查询业务列表或创建业务的返回结果中获取。业务 ID 与业务标识 `key` 不同。

**返回参数说明**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| `id` | string | 业务 ID，供查询、编辑、删除及查询关联环境时使用 |
| `name` | string | 业务名称 |
| `key` | string | 业务唯一标识，创建后不可修改 |
| `project` | string | 关联项目的项目标识 |
| `type` | string | 业务类型 |
| `owner` | string | 负责人用户 ID |
| `description` | string | 业务描述 |
| `repository.codehost_id` | integer | 代码源 ID |
| `repository.repo_owner` | string | 代码仓库所属用户或组织 |
| `repository.repo_name` | string | 代码仓库名称 |
| `testing_service_name` | string | 关联的测试服务名称 |
| `production_service_name` | string | 关联的生产服务名称 |
| `custom_fields` | object | 自定义字段，键为字段标识 |
| `create_time` | integer | 创建时间，Unix 时间戳，单位为秒 |
| `update_time` | integer | 更新时间，Unix 时间戳，单位为秒 |

未关联代码仓库时不返回 `repository`。

**返回示例**

```json
{
  "id": "6aff00000000000000000001",
  "name": "订单服务",
  "key": "order-service",
  "project": "shop",
  "type": "服务",
  "owner": "",
  "description": "订单处理服务",
  "repository": {
    "codehost_id": 1,
    "repo_owner": "shop-team",
    "repo_name": "order-service"
  },
  "testing_service_name": "order-service",
  "production_service_name": "",
  "custom_fields": {"priority": "P0"},
  "create_time": 1795132800,
  "update_time": 1795132800
}
```

## 创建业务

**请求**

```text
POST /openapi/application/applications
```

**Body 参数说明**

| 参数名 | 类型 | 描述 | 必填 |
| --- | --- | --- | --- |
| `name` | string | 业务名称，不能全部为空白字符 | 是 |
| `key` | string | 业务唯一标识，不能全部为空白字符，创建后不可修改 | 是 |
| `project` | string | 关联项目的项目标识，不能全部为空白字符 | 是 |
| `type` | string | 业务类型，按业务模型中配置的类型填写 | 否 |
| `owner` | string | 负责人用户 ID | 否 |
| `description` | string | 业务描述 | 否 |
| `repository` | object | 关联的代码仓库，参数见下表 | 否 |
| `testing_service_name` | string | 关联的测试服务名称，须属于 `project` 指定的项目 | 否 |
| `production_service_name` | string | 关联的生产服务名称，须属于 `project` 指定的项目 | 否 |
| `custom_fields` | object | 自定义字段；业务模型配置为必填的字段必须提供有效值 | 条件必填 |

**repository 参数说明**

传入 `repository` 时，下列三个参数均必填，且不能全部为空白字符。

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| `codehost_name` | string | 已接入 Zadig 的代码源名称 |
| `repo_owner` | string | 仓库所属用户或组织 |
| `repo_name` | string | 仓库名称 |

**请求示例**

示例使用已存在的项目 `shop`、测试服务 `order-service` 和代码源 `gitlab`；`priority` 为已创建的单选字段。

```json
{
  "name": "订单服务",
  "key": "order-service",
  "project": "shop",
  "type": "服务",
  "description": "订单处理服务",
  "repository": {
    "codehost_name": "gitlab",
    "repo_owner": "shop-team",
    "repo_name": "order-service"
  },
  "testing_service_name": "order-service",
  "custom_fields": {"priority": "P0"}
}
```

**成功返回说明**

返回创建后的业务对象，字段说明见“查询业务详情”。`id` 和时间由系统生成。

## 批量导入业务

**请求**

```text
POST /openapi/application/applications/bulk
```

请求体为业务对象数组，每个对象的参数和校验规则同“创建业务”。

**请求示例**

```json
[
  {"name": "订单服务", "key": "order-service", "project": "shop"},
  {"name": "支付服务", "key": "payment-service", "project": "shop"}
]
```

若业务模型中存在必填自定义字段，每个对象还需补齐相应的 `custom_fields`。

成功返回 `{"message":"success"}`。导入失败后，先查询已导入的业务，再决定重试范围，避免重复创建。

## 编辑业务

**请求**

```text
PUT /openapi/application/applications/:id
```

路径参数 `id` 为业务 ID。Body 参数同“创建业务”，`name`、`key`、`project` 必填，`key` 必须与原值一致。更新时请包含需要保留的可选配置和自定义字段，`repository` 按以下规则处理：

| repository 传参方式 | 行为 |
| --- | --- |
| 不传或传 `null` | 保留原代码仓库关联 |
| 传入完整对象 | 使用 `codehost_name`、`repo_owner`、`repo_name` 更新代码仓库关联 |
| 传 `{}`、缺少必填子字段，或必填子字段为空白字符串 | 参数校验失败 |

**请求示例**

```json
{
  "name": "订单服务",
  "key": "order-service",
  "project": "shop",
  "type": "服务",
  "owner": "",
  "description": "订单查询与处理服务",
  "repository": {
    "codehost_name": "gitlab",
    "repo_owner": "shop-team",
    "repo_name": "order-service"
  },
  "testing_service_name": "order-service",
  "production_service_name": "",
  "custom_fields": {"priority": "P1"}
}
```

成功返回 `{"message":"success"}`。

## 删除业务

**请求**

```text
DELETE /openapi/application/applications/:id
```

路径参数 `id` 为业务 ID。删除业务时解除测试服务和生产服务的关联，服务本身不会删除。

成功返回 `{"message":"success"}`。

## 查询业务关联环境

**请求**

```text
GET /openapi/application/applications/:id/envs
```

路径参数 `id` 为业务 ID。返回关联的测试服务和生产服务已部署的环境；没有匹配环境时返回空数组。

**返回参数说明**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| `project_name` | string | 项目标识 |
| `env_name` | string | 环境名称 |
| `env_alias` | string | 环境别名 |
| `production` | boolean | 是否为生产环境 |
| `name` | string | 服务展示名称 |
| `type` | string | 部署类型，如 `k8s`、`helm`、`pm` |
| `status` | string | 服务状态，随部署类型而异 |
| `images` | string[] | 服务镜像列表，适用于返回镜像信息的部署类型 |
| `chart_version` | string | Helm Chart 版本 |
| `update_time` | integer | 更新时间，Unix 时间戳，单位为秒；未获取到时为 0 |
| `error` | string | 当前条目的信息获取错误；无错误时为空字符串 |

**返回示例**

```json
[
  {
    "project_name": "shop",
    "env_name": "dev",
    "env_alias": "开发环境",
    "production": false,
    "name": "order-service",
    "type": "k8s",
    "status": "Running",
    "images": ["registry.example.com/shop/order-service:v1.0.0"],
    "chart_version": "",
    "update_time": 1795132800,
    "error": ""
  }
]
```

## 查询业务模型字段

**请求**

```text
GET /openapi/application/fields
```

返回内置字段和自定义字段的定义。内置字段通过业务对象的对应参数填写；自定义字段通过 `custom_fields` 填写，例如字段 `priority` 的值写为 `{"custom_fields":{"priority":"P0"}}`。

**返回参数说明**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| `id` | string | 字段 ID，用于编辑和删除字段 |
| `key` | string | 字段标识 |
| `name` | string | 字段展示名称 |
| `type` | string | 字段类型，见下文 |
| `default` | 取决于字段类型 | 字段默认值 |
| `options` | string[] | 单选、多选字段的可选项 |
| `unique` | boolean | 是否配置为值唯一 |
| `required` | boolean | 是否必填 |
| `show_in_list` | boolean | 是否在业务列表展示 |
| `description` | string | 字段描述 |
| `source` | string | 字段来源：`builtin` 为内置字段，`custom` 为自定义字段 |
| `create_time` | integer | 创建时间，Unix 时间戳，单位为秒 |
| `update_time` | integer | 更新时间，Unix 时间戳，单位为秒 |

**返回示例**

以下为一个自定义字段的返回示例。

```json
[
  {
    "id": "6aff00000000000000000002",
    "key": "priority",
    "name": "优先级",
    "type": "single_select",
    "default": "P1",
    "options": ["P0", "P1"],
    "unique": false,
    "required": false,
    "show_in_list": true,
    "description": "业务优先级",
    "source": "custom",
    "create_time": 1795132800,
    "update_time": 1795132800
  }
]
```

**自定义字段类型与值格式**

| type | 含义 | custom_fields 中的值类型 |
| --- | --- | --- |
| `text` | 文本 | string |
| `number` | 数字 | number |
| `bool` | 布尔 | boolean |
| `datetime` | 日期时间 | number |
| `single_select` | 单选 | string，必须属于 `options` |
| `multi_select` | 多选 | string[]，每个值必须属于 `options` |
| `link` | 链接 | string |
| `user` | 用户 | string，用户 ID |
| `user_group` | 用户组 | string，用户组 ID |
| `project` | 项目 | string，项目标识 |

## 创建业务模型字段

**请求**

```text
POST /openapi/application/fields
```

**Body 参数说明**

| 参数名 | 类型 | 描述 | 必填 |
| --- | --- | --- | --- |
| `key` | string | 字段唯一标识，对应 `custom_fields` 中的键；不能为空白字符 | 是 |
| `name` | string | 字段展示名称，不能为空白字符 | 是 |
| `type` | string | 自定义字段类型，见“查询业务模型字段” | 是 |
| `default` | 取决于字段类型 | 默认值，使用与字段类型一致的格式 | 否 |
| `options` | string[] | 单选、多选字段必须提供非空选项列表，其他类型不传 | 条件必填 |
| `unique` | boolean | 是否配置为值唯一，默认 `false`；多选类型不能设为 `true` | 否 |
| `required` | boolean | 是否必填，默认 `false` | 否 |
| `show_in_list` | boolean | 是否在业务列表展示，默认 `false` | 否 |
| `description` | string | 字段描述 | 否 |

**请求示例**

```json
{
  "key": "priority",
  "name": "优先级",
  "type": "single_select",
  "default": "P1",
  "options": ["P0", "P1"],
  "unique": false,
  "required": false,
  "show_in_list": true,
  "description": "业务优先级"
}
```

成功返回创建后的字段对象，字段说明见“查询业务模型字段”。

## 编辑业务模型字段

**请求**

```text
PUT /openapi/application/fields/:id
```

路径参数 `id` 为字段 ID，从“查询业务模型字段”获取。Body 参数同“创建业务模型字段”，需提交更新后的完整字段定义，包括需要保留的默认值、选项和展示配置。

**请求示例**

```json
{
  "key": "priority",
  "name": "优先级",
  "type": "single_select",
  "default": "P1",
  "options": ["P0", "P1", "P2"],
  "unique": false,
  "required": false,
  "show_in_list": true,
  "description": "业务优先级"
}
```

成功返回 `{"message":"success"}`。

## 删除业务模型字段

**请求**

```text
DELETE /openapi/application/fields/:id
```

路径参数 `id` 为字段 ID。删除自定义字段时，同时清理业务中该字段的值。

成功返回 `{"message":"success"}`。
