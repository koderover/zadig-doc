## 获取服务列表

### 测试服务

**请求**

```
GET /openapi/service/yaml/services?projectKey=<项目标识>
```
**Query 参数说明**

| 参数名       | 类型   | 描述     | 必填 |
| ------------ | ------ | -------- | ---- |
| `projectKey` | string | 项目标识 | 是   |

**返回说明**

| 参数名         | 类型                        | 描述                   |
| -------------- | --------------------------- | ---------------------- |
| `service_name` | string                      | 服务名称               |
| `type`         | string                      | 服务类型，固定值 `k8s` |
| `containers`   | [][Container](#Container-1) | 服务组件列表           |

<h4 id="Container-1">Container 参数说明</h4>

| 参数名       | 类型   | 描述               |
| ------------ | ------ | ------------------ |
| `name`       | string | 服务组件名称       |
| `image`      | string | 服务组件的镜像信息 |
| `image_name` | string | 服务组件的镜像名称 |

**返回示例**

::: details
```json
{
    "service": [
        {
            "service_name": "service-1",
            "type": "k8s",
            "containers": [
                {
                    "name": "myapp-1",
                    "image": "koderover.tencentcloudcr.com/koderover-demo/myapp-1:v0.1__linux_amd64",
                    "image_name": "myapp-1"
                }
            ]
        }
    ]
}
```
:::

## 获取服务详情

适用于 K8s YAML 服务。Helm 服务请使用[获取 Helm 服务详情](#获取-helm-服务详情)。

### 测试服务

**请求**

```
GET /openapi/service/yaml/:serviceName?projectKey=<项目标识>
```

**路径参数说明**

| 参数名        | 类型   | 描述     | 必填 |
| ------------- | ------ | -------- | ---- |
| `serviceName` | string | 服务名称 | 是   |

**Query 参数说明**

| 参数名       | 类型   | 描述     | 必填 |
| ------------ | ------ | -------- | ---- |
| `projectKey` | string | 项目标识 | 是   |

**返回说明**

| 参数名                 | 类型                        | 描述                   |
| ---------------------- | --------------------------- | ---------------------- |
| `service_name`         | string                      | 服务名称               |
| `created_by`           | string                      | 服务创建者             |
| `created_time`         | int                         | 服务创建时间           |
| `type`                 | string                      | 服务类型，固定为 `k8s` |
| `containers`           | [][Container](#Container-3) | 服务组件列表           |
| `service_variable_kvs` | [][KeyVal](#KeyVal-1)       | 服务变量列表           |
| `yaml`                 | string                      | 服务配置的 YAML 内容   |

<h4 id="Container-3">Container 参数说明</h4>

| 参数名       | 类型   | 描述               |
| ------------ | ------ | ------------------ |
| `name`       | string | 服务组件名称       |
| `image`      | string | 服务组件的镜像信息 |
| `image_name` | string | 服务组件的镜像名称 |

<h4 id="KeyVal-1">KeyVal 参数说明</h4>

| 参数名    | 说明                                               | 类型     | 必填 |
| --------- | -------------------------------------------------- | -------- | ---- |
| `key`     | 变量的键                                           | string   | 是   |
| `value`   | 变量的值，若有嵌套值，使用 json 格式               | any      | 是   |
| `type`    | 变量值的类型，有四种类型：bool、string、enum、yaml | string   | 是   |
| `options` | 变量可选值列表，当 `type` 为 `enum` 时该字段有意义 | []string | 否   |
| `desc`    | 变量描述信息                                       | String   | 否   |

**返回示例**

:::details

```json
{
    "service_name": "service2",
    "type": "k8s",
    "created_by": "admin",
    "created_time": 1689660993,
    "yaml": "apiVersion: apps/v1\nkind: Deployment\nmetadata:\n  name: service2\n  labels: \n    app.kubernetes.io/name: ai-test-2\n    app.kubernetes.io/instance: service2\n    hello: test\nspec:\n  selector:\n    matchLabels:\n      app.kubernetes.io/name: ai-test-2\n      app.kubernetes.io/instance: service2\n  replicas: 1\n  template:\n    metadata: \n      labels:\n        app.kubernetes.io/name: ai-test-2\n        app.kubernetes.io/instance: service2\n        hello: {{.world}}\n    spec:\n      containers:\n        - name: service2\n          image: koderover.******.com/koderover-demo/service2:latest\n          imagePullPolicy: Always \n          command:\n            - /workspace/service2\n          ports:\n            - protocol: TCP\n              containerPort: {{.port}}\n          resources:\n            limits:\n              memory: {{.memoryLimit}}\n              cpu: {{.cpuLimit}}\n---\napiVersion: v1\nkind: Service\nmetadata:\n  name: service2\n  labels:\n    app.kubernetes.io/name: ai-test-2\n    app.kubernetes.io/instance: service2\nspec:\n  type: NodePort\n  ports:\n    - protocol: TCP\n      port: {{.port}}\n      targetPort: {{.port}}",
    "containers": [
        {
            "name": "service2",
            "image": "koderover.******.com/koderover-demo/service2:latest",
            "image_name": "service2"
        }
    ],
    "service_variable_kvs": [
        {
            "key": "cpuLimit",
            "value": "55m",
            "type": "string",
            "options": [],
            "desc": ""
        }
    ]
}
```

:::

## 获取服务标签

**请求**

```

```
**路径参数说明**

| 参数名        | 类型   | 描述     | 必填 |
| ------------- | ------ | -------- | ---- |

| 参数名       | 类型   | 描述     | 必填 |
| ------------ | ------ | -------- | ---- |
| `projectKey` | string | 项目标识 | 是   |

**返回实例**


正确时返回

```json
[
  {
    "key": "key",
    "value": "value"
  },
  ...
]
```

错误时返回

```json
{
  "code": 500,
  "description": "...",
  "message": "Internal Error"
```

## 使用模板新建服务

### 测试服务

**请求**

```
POST /openapi/service/template/load/yaml
```

**Body 参数说明**

| 参数名          | 说明              | 类型                  | 必填 |
| --------------- | ----------------- | --------------------- | ---- |
| `service_name`  | 服务名称          | string                | 是   |
| `project_key`   | 项目标识          | string                | 是   |
| `template_name` | K8s Yaml 模板名称 | string                | 是   |
| `auto_sync`     | 自动同步开关      | bool                  | 否   |
| `variable_yaml` | 模板中的变量信息  | [][KeyVal](#KeyVal-5) | 否   |

<h4 id="KeyVal-5">KeyVal 参数说明</h4>

| 参数名  | 说明                                 | 类型   | 必填 |
| ------- | ------------------------------------ | ------ | ---- |
| `key`   | 变量的键值                           | string | 是   |
| `value` | 变量的值，若有嵌套值，使用 json 格式 | any    | 是   |

**Body 参数示例**

使用模板 `microservice-template` 为项目 `demo` 新建服务 `service1`：

::: details
``` json
{
    "service_name": "service1",
    "project_key":"demo",
    "template_name": "microservice-template",
    "auto_sync": true,
    "variable_yaml": [
        {
            "key": "cpuLimit",
            "value": "100m"
        },
        {
            "key": "memoryLimit",
            "value": "100Mi"
        },
        {
            "key": "port",
            "value": "20221"
        }
    ]
}
```
:::

**返回**

```json
{
  "message": "success"
}
```

## 从代码库新建 K8s YAML 服务

**请求**

```
POST /openapi/service/loader/load?codehostName=<代码源名称>&repoName=<代码库名称>&branchName=<分支名称>&remoteName=<远端名称>&repoOwner=<仓库拥有者>&namespace=<仓库命名空间>&production=<是否生产服务>
```

**Query 参数说明**

| 参数名         | 类型   | 描述                                                         | 必填 |
| -------------- | ------ | ------------------------------------------------------------ | ---- |
| `codehostName` | string | 代码源名称                                                   | 是   |
| `repoName`     | string | 代码库名称                                                   | 是   |
| `branchName`   | string | 服务配置所在分支                                             | 是   |
| `remoteName`   | string | Git 远端名称，Gerrit、Gitee 和 Gitee Enterprise 场景使用；为空默认为 `origin` | 否   |
| `repoOwner`    | string | 仓库拥有者/组织名                                      | 是   |
| `namespace`    | string | GitHub/GitLab 仓库命名空间，为空默认使用 `repoOwner`   | 否   |
| `production`   | bool   | 是否创建生产服务，仅值为 `true` 时创建生产服务，默认为 `false` | 否   |

**Body 参数说明**

| 参数名          | 说明         | 类型                                      | 必填 |
| --------------- | ------------ | ----------------------------------------- | ---- |
| `product_name`  | 项目标识     | string                                    | 是   |
| `service_paths` | 服务路径列表 | [][LoadServicePath](#LoadServicePath-1)   | 是   |

<h4 id="LoadServicePath-1">LoadServicePath 参数说明</h4>

| 参数名         | 说明                                                         | 类型   | 必填 |
| -------------- | ------------------------------------------------------------ | ------ | ---- |
| `service_name` | 服务名称                                                     | string | 是   |
| `path`         | 服务配置文件或目录在代码库中的相对路径；`is_dir` 为 `true` 时可传空字符串表示仓库根目录 | string | 条件必填 |
| `is_dir`       | 是否为目录，`true` 表示从目录加载，`false` 表示从单个 YAML 文件加载，默认为 `false` | bool   | 否   |

**请求示例**

从代码源 `github-demo` 的 `main` 分支为项目 `demo` 新建测试服务：

```
POST /openapi/service/loader/load?codehostName=github-demo&repoName=demo&branchName=main&repoOwner=koderover&production=false
```

**Body 参数示例**

::: details
``` json
{
    "product_name": "demo",
    "service_paths": [
        {
            "service_name": "backend",
            "path": "services/backend/deployment.yaml",
            "is_dir": false
        }
    ]
}
```
:::

**返回**

```json
{
  "message": "success"
}
```

## 查询代码库中的 Helm Values

扫描代码库中的指定路径，返回可用于[批量导入 Helm 服务](#批量导入-helm-服务)的 Values 文件路径。

- 目录只扫描当前层，不递归子目录。
- 只识别扩展名为 `.yaml` 或 `.yml` 的文件，跳过 `Chart.yaml`（不区分大小写）和路径中包含 `templates` 目录的文件。
- 直接指定文件时，文件须符合上述规则、存在且内容不为空，否则请求失败。
- 多个路径扫描到同一文件时只返回一次；返回的文件总数超过 100 个时请求失败。

**请求**

| `branch`       | 分支名称                                                     | string                                        | 是   |

<h4 id="HelmValuesScanPath-1">HelmValuesScanPath 参数说明</h4>

## 批量导入 Helm 服务

使用同一个 Helm 模板，为每个 Values 文件新建一个 Helm 服务。可以先调用[查询代码库中的 Helm Values](#查询代码库中的-helm-values)获取 Values 文件路径。

- 服务名称取 Values 文件名去掉扩展名后转为小写，例如 `values/Service1.yaml` 对应服务 `service1`。
- 同一请求中多个文件对应同一服务名称时，只创建第一个，其余记入 `failedServices`。
- 服务已存在、Values 文件不存在或内容为空时，该文件记入 `failedServices`，不影响其他文件。
- 每次 1 到 100 个 Values 文件。
- 新建测试服务后，若项目开启了自动部署，会将服务自动部署到测试环境；生产服务不会自动部署。

**请求**

```
POST /openapi/service/helm/bulk?projectKey=<项目标识>&production=<是否生产服务>
```

**Query 参数说明**

| 参数名       | 类型   | 描述                             | 必填 |
| ------------ | ------ | -------------------------------- | ---- |
| `projectKey` | string | 项目标识                         | 是   |
| `production` | bool   | 是否创建生产服务，默认为 `false` | 否   |

**Body 参数说明**

| 参数名         | 说明                                                                                                               | 类型     | 必填 |
| -------------- | ------------------------------------------------------------------------------------------------------------------ | -------- | ---- |
| `templateName` | Helm 模板名称                                                                                                      | string   | 是   |
| `codehostName` | Values 文件所在代码源名称，支持系统级和项目级代码源                                                                | string   | 是   |
| `owner`        | 仓库拥有者/组织名                                                                                                  | string   | 是   |
| `namespace`    | 仓库命名空间，GitLab 多层 group 时使用；为空默认使用 `owner`                                                       | string   | 否   |
| `repo`         | 代码库名称                                                                                                         | string   | 是   |
| `branch`       | 分支名称                                                                                                           | string   | 是   |
| `valuesPaths`  | Values 文件路径列表，1 到 100 个；路径规则与[查询代码库中的 Helm Values](#查询代码库中的-helm-values)相同，不能以 `/` 开头，不能包含 `..` | []string | 是   |
| `autoSync`     | 是否开启模板自动同步，默认为 `false`                                                                               | bool     | 否   |

**Body 参数示例**

使用模板 `general-chart` 为项目 `demo` 批量导入服务：

::: details
```json

    "templateName": "general-chart",
    "codehostName": "github-demo",
    "owner": "koderover",
    "repo": "helm-values",

        "values/service1.yaml",
        "values/service2.yaml"
    ],

}
```

**返回说明**

| `failedServices`  | 创建失败的服务列表                                                                   | [][FailedHelmService](#FailedHelmService-2) |
| `autoDeployError` | 服务已创建，但触发自动部署到测试环境失败时的错误信息；没有此类错误时不返回该字段 | string                                      |

<h4 id="FailedHelmService-2">FailedHelmService 参数说明</h4>

| 参数名  | 说明                       | 类型   |
| ------- | -------------------------- | ------ |
| `path`  | 创建失败的 Values 文件路径 | string |
| `error` | 失败原因                   | string |

**返回示例**

::: details
```json

    "successServices": [
        "service1",
        "service2"
    ],
    "failedServices": []
```

## 更新 Helm 服务

更新 Helm 服务的 Values 内容。

- 仅支持从 Helm 模板创建的服务，即 `source` 为 `chartTemplate` 的服务。
- 更新后模板自动同步不再生效，`template_auto_sync_active` 变为 `false`。
- 需传入当前版本号 `expected_revision`，与服务当前版本不一致时返回 409，需重新获取后再更新。
- Values 内容未变化时不生成新版本。
- 测试服务更新后，若项目开启了自动部署，会自动更新到环境中。

**请求**

```
PUT /openapi/service/helm/:serviceName?projectKey=<项目标识>&production=<是否生产服务>
```

**路径参数说明**

| 参数名        | 类型   | 描述     | 必填 |
| ------------- | ------ | -------- | ---- |
| `serviceName` | string | 服务名称 | 是   |

**Query 参数说明**

| 参数名       | 类型   | 描述                           | 必填 |
| ------------ | ------ | ------------------------------ | ---- |
| `projectKey` | string | 项目标识                       | 是   |
| `production` | bool   | 是否为生产服务，默认为 `false` | 否   |

**Body 参数说明**

| 参数名              | 说明                                                             | 类型   | 必填 |
| ------------------- | ---------------------------------------------------------------- | ------ | ---- |
| `expected_revision` | 服务当前版本号，取自[获取 Helm 服务详情](#获取-helm-服务详情)的 `revision`，需大于 0 | int    | 是   |
| `values_yaml`       | 新的 Values 内容，不能为空                                       | string | 是   |

**Body 参数示例**

```json
{
    "expected_revision": 3,
    "values_yaml": "image:\n  repository: koderover.tencentcloudcr.com/koderover-demo/service1\n  tag: v1.0.1\nreplicaCount: 2\n"
```

**返回说明**

| 参数名     | 类型 | 描述               |

```json

}
```

## 更新服务变量

### 测试服务

**请求**

```
PUT /openapi/service/yaml/:serviceName/variable?projectKey=<projectKey>
```

**路径参数说明**

| 参数名        | 类型   | 描述     | 必填 |
| ------------- | ------ | -------- | ---- |
| `serviceName` | string | 服务名称 | 是   |

**Query 参数说明**

| 参数名       | 类型   | 描述     | 必填 |
| ------------ | ------ | -------- | ---- |
| `projectKey` | string | 项目标识 | 是   |

**Body 参数说明**

| 参数名                 | 说明         | 类型                  | 必填 |
| ---------------------- | ------------ | --------------------- | ---- |
| `service_variable_kvs` | 服务变量列表 | [][KeyVal](#KeyVal-9) | 是   |

<h4 id="KeyVal-9">KeyVal 参数说明</h4>

| 参数名    | 说明                                               | 类型     | 必填 |
| --------- | -------------------------------------------------- | -------- | ---- |
| `key`     | 变量的键                                           | string   | 是   |
| `value`   | 变量的值，若有嵌套值，使用 json 格式               | any      | 是   |
| `type`    | 变量值的类型，有四种类型：bool、string、enum、yaml | string   | 是   |
| `options` | 变量可选值列表，当 `type` 为 `enum` 时该字段有意义 | []string | 否   |
| `desc`    | 变量描述信息                                       | String   | 否   |

**Body 参数示例**

::: details
```json
{
    "service_variable_kvs": [
        {
            "key":"cpu",
            "value":"12m",
            "type":"string",
          	"options":[],
          	"desc":""
        }
    ]
}
```
:::

**返回**

```json
{
  "message": "success"
}
```

## 使用模板新建 Helm 服务

**请求**

```
POST /openapi/service/template/load/helm?projectKey=<projectKey>
```

**Body 参数说明**

| 参数名          | 说明             | 类型                  | 必填 |
| --------------- | ---------------- | --------------------- | ---- |
| `project_key`   | 项目标识         | string                | 是   |
| `service_name`  | 服务名称         | string                | 是   |
| `production`    | 是否生产环境     | bool                  | 否   |
| `template_name` | Helm 模板名称    | string                | 是   |
| `values_yaml`   | values yaml 内容 | string                | 否   |
| `variables`     | 模板中的变量信息 | [][KeyVal](#KeyVal-11) | 否   |
| `auto_sync`     | 自动同步开关     | bool                  | 否   |

<h4 id="KeyVal-11">KeyVal 参数说明</h4>

| 参数名  | 说明                                 | 类型   | 必填 |
| ------- | ------------------------------------ | ------ | ---- |
| `key`   | 变量的键值                           | string | 是   |
| `value` | 变量的值，若有嵌套值，使用 json 格式 | any    | 是   |

**Body 参数示例**

使用模板 `general-chart` 为项目 `multi-chart` 新建服务 `api-test`：

::: details
``` json
{
    "auto_sync": true,
    "production": false,
    "project_key": "multi-chart",
    "service_name": "api-test",
    "template_name": "general-chart",
    "values_yaml": "aa: bb\ncc: dd",
    "variables": [
        {
            "key": "port",
            "value": 20012
        }
    ]
}
```
:::

**返回**

```json
{
  "message": "success"
}
```
