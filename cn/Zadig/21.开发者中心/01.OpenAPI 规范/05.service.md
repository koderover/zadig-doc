## 获取服务列表

### 测试服务

**请求**

```
GET /openapi/service/yaml/services?projectKey=<项目标识>
```
**Query 参数说明**

| 参数名       | 类型   | 描述     | 必填 |
| ------------ | ------ | -------- | ---- |
| `projectKey` | string | 项目标识 | 是   |

**返回说明**

| 参数名         | 类型                        | 描述                   |
| -------------- | --------------------------- | ---------------------- |
| `service_name` | string                      | 服务名称               |
| `type`         | string                      | 服务类型，固定值 `k8s` |
| `containers`   | [][Container](#Container-1) | 服务组件列表           |

<h4 id="Container-1">Container 参数说明</h4>

| 参数名       | 类型   | 描述               |
| ------------ | ------ | ------------------ |
| `name`       | string | 服务组件名称       |
| `image`      | string | 服务组件的镜像信息 |
| `image_name` | string | 服务组件的镜像名称 |

**返回示例**

::: details
```json
{
    "service": [
        {
            "service_name": "service-1",
            "type": "k8s",
            "containers": [
                {
                    "name": "myapp-1",
                    "image": "koderover.tencentcloudcr.com/koderover-demo/myapp-1:v0.1__linux_amd64",
                    "image_name": "myapp-1"
                }
            ]
        }
    ]
}
```
:::

## 获取服务详情

### 测试服务

**请求**

```
GET /openapi/service/yaml/:serviceName?projectKey=<项目标识>
```

**路径参数说明**

| 参数名        | 类型   | 描述     | 必填 |
| ------------- | ------ | -------- | ---- |
| `serviceName` | string | 服务名称 | 是   |

**Query 参数说明**

| 参数名       | 类型   | 描述     | 必填 |
| ------------ | ------ | -------- | ---- |
| `projectKey` | string | 项目标识 | 是   |

**返回说明**

| 参数名                 | 类型                        | 描述                   |
| ---------------------- | --------------------------- | ---------------------- |
| `service_name`         | string                      | 服务名称               |
| `created_by`           | string                      | 服务创建者             |
| `created_time`         | int                         | 服务创建时间           |
| `type`                 | string                      | 服务类型，固定为 `k8s` |
| `containers`           | [][Container](#Container-3) | 服务组件列表           |
| `service_variable_kvs` | [][KeyVal](#KeyVal-1)       | 服务变量列表           |
| `yaml`                 | string                      | 服务配置的 YAML 内容   |

<h4 id="Container-3">Container 参数说明</h4>

| 参数名       | 类型   | 描述               |
| ------------ | ------ | ------------------ |
| `name`       | string | 服务组件名称       |
| `image`      | string | 服务组件的镜像信息 |
| `image_name` | string | 服务组件的镜像名称 |

| `desc`    | 变量描述信息                                       | String   | 否   |

**返回示例**

```json
        {
            "name": "service2",

        }
    ],
    "service_variable_kvs": [
        {
            "key": "cpuLimit",
```

## 获取服务标签

```

```

| 参数名        | 类型   | 描述     | 必填 |

| ------------ | ------ | -------- | ---- |

**返回实例**


正确时返回

```json
[
  {
    "key": "key",
    "value": "value"
  },
  ...
]
```

```json
{
  "code": 500,
```

## 使用模板新建服务

### 测试服务

**请求**

```
POST /openapi/service/template/load/yaml
```

**Body 参数说明**

| 参数名          | 说明              | 类型                  | 必填 |
| --------------- | ----------------- | --------------------- | ---- |
| `service_name`  | 服务名称          | string                | 是   |
| `project_key`   | 项目标识          | string                | 是   |
| `template_name` | K8s Yaml 模板名称 | string                | 是   |
| `auto_sync`     | 自动同步开关      | bool                  | 否   |
| `variable_yaml` | 模板中的变量信息  | [][KeyVal](#KeyVal-5) | 否   |

<h4 id="KeyVal-5">KeyVal 参数说明</h4>

| 参数名  | 说明                                 | 类型   | 必填 |
| ------- | ------------------------------------ | ------ | ---- |
| `key`   | 变量的键值                           | string | 是   |
| `value` | 变量的值，若有嵌套值，使用 json 格式 | any    | 是   |

**Body 参数示例**

使用模板 `microservice-template` 为项目 `demo` 新建服务 `service1`：

::: details
``` json
{
    "service_name": "service1",
    "project_key":"demo",
    "template_name": "microservice-template",
    "auto_sync": true,
    "variable_yaml": [
        {
            "key": "cpuLimit",
            "value": "100m"
        },
        {
            "key": "memoryLimit",
            "value": "100Mi"
        },
        {
            "key": "port",
            "value": "20221"
        }
    ]
}
```
:::

**返回**

```json
{
  "message": "success"
}
```

## 从代码库新建 K8s YAML 服务

**请求**

```
POST /openapi/service/loader/load?codehostName=<代码源名称>&repoName=<代码库名称>&branchName=<分支名称>&remoteName=<远端名称>&repoOwner=<仓库拥有者>&namespace=<仓库命名空间>&production=<是否生产服务>
```

**Query 参数说明**

| 参数名         | 类型   | 描述                                                         | 必填 |
| -------------- | ------ | ------------------------------------------------------------ | ---- |
| `codehostName` | string | 代码源名称                                                   | 是   |
| `repoName`     | string | 代码库名称                                                   | 是   |
| `branchName`   | string | 服务配置所在分支                                             | 是   |
| `remoteName`   | string | Git 远端名称，Gerrit、Gitee 和 Gitee Enterprise 场景使用；为空默认为 `origin` | 否   |
| `repoOwner`    | string | 仓库拥有者/组织名                                      | 是   |
| `namespace`    | string | GitHub/GitLab 仓库命名空间，为空默认使用 `repoOwner`   | 否   |
| `production`   | bool   | 是否创建生产服务，仅值为 `true` 时创建生产服务，默认为 `false` | 否   |

**Body 参数说明**

| 参数名          | 说明         | 类型                                      | 必填 |
| --------------- | ------------ | ----------------------------------------- | ---- |
| `product_name`  | 项目标识     | string                                    | 是   |
| `service_paths` | 服务路径列表 | [][LoadServicePath](#LoadServicePath-1)   | 是   |

<h4 id="LoadServicePath-1">LoadServicePath 参数说明</h4>

| 参数名         | 说明                                                         | 类型   | 必填 |
| -------------- | ------------------------------------------------------------ | ------ | ---- |
| `service_name` | 服务名称                                                     | string | 是   |
| `path`         | 服务配置文件或目录在代码库中的相对路径；`is_dir` 为 `true` 时可传空字符串表示仓库根目录 | string | 条件必填 |
| `is_dir`       | 是否为目录，`true` 表示从目录加载，`false` 表示从单个 YAML 文件加载，默认为 `false` | bool   | 否   |

**请求示例**

从代码源 `github-demo` 的 `main` 分支为项目 `demo` 新建测试服务：

```
POST /openapi/service/loader/load?codehostName=github-demo&repoName=demo&branchName=main&repoOwner=koderover&production=false
```

**Body 参数示例**

::: details
``` json
{
    "product_name": "demo",
    "service_paths": [
        {
            "service_name": "backend",
            "path": "services/backend/deployment.yaml",
            "is_dir": false
        }
    ]
}
```
:::

**返回**

```json
{
  "message": "success"
}
```

**Body 参数说明**

| 参数名       | 说明                                                                 | 类型   | 必填 |
| ------------ | -------------------------------------------------------------------- | ------ | ---- |
| `source`     | 服务来源枚举，取值及含义见下表                                     | string | 是   |
| `production` | 是否创建生产服务，默认为 `false`                                     | bool   | 否   |
| `createFrom` | 服务来源配置，不同 `source` 对应字段见下方说明                       | object | 是   |

<h4 id="OpenAPIHelmLoadSource-1">source 取值说明</h4>

| 取值               | 含义                                                               |
| ------------------ | ------------------------------------------------------------------ |
| `repo`             | 已接入的 GitHub、GitLab 或 `other` 类型通用 Git 代码源              |
| `gerrit`           | 已接入的 Gerrit 代码源                                             |
| `gitee`            | 已接入的 Gitee 代码源                                              |
| `gitee-enterprise` | 已接入的 Gitee Enterprise 代码源                                   |
| `publicRepo`       | 公开 GitHub 代码库                                                 |
| `chartRepo`        | 已接入的 Chart 仓库                                                |

<h4 id="OpenAPICreateFromRepo-1">source 为已接入代码源时 createFrom 参数说明</h4>

适用于 `repo`、`gerrit`、`gitee` 和 `gitee-enterprise`。

| 参数名         | 说明                                                         | 类型     | 必填 |
| -------------- | ------------------------------------------------------------ | -------- | ---- |
| `codehostName` | 代码源名称                                                   | string   | 是   |
| `owner`        | 仓库拥有者/组织名                                            | string   | 是   |
| `namespace`    | 仓库命名空间，GitLab 多层 group 时使用；为空默认使用 `owner` | string   | 否   |
| `repo`         | 代码库名称                                                   | string   | 是   |
| `branch`       | 分支名称                                                     | string   | 是   |
| `paths`        | Chart 所在路径列表，支持传多个路径                           | []string | 是   |

<h4 id="OpenAPICreateFromPublicRepo-1">source 为 publicRepo 时 createFrom 参数说明</h4>

| 参数名     | 说明                               | 类型     | 必填 |
| ---------- | ---------------------------------- | -------- | ---- |
| `repoLink` | 公开仓库地址                       | string   | 是   |
| `paths`    | Chart 所在路径列表，支持传多个路径 | []string | 是   |

<h4 id="OpenAPICreateFromChartRepo-1">source 为 chartRepo 时 createFrom 参数说明</h4>

| 参数名           | 说明        | 类型   | 必填 |
| ---------------- | ----------- | ------ | ---- |
| `chartRepoName`  | Chart 仓库名称 | string | 是   |
| `chartName`      | Chart 名称  | string | 是   |
| `chartVersion`   | Chart 版本约束；为空时不指定版本，由 Helm 解析可用版本 | string | 否   |

**Body 参数示例**

从代码源 `github-demo` 的 `main` 分支为项目 `demo` 新建 Helm 服务：

::: details
``` json
{
    "source": "repo",
    "production": false,
    "createFrom": {
        "codehostName": "github-demo",
        "owner": "koderover",
        "repo": "helm-charts",
        "branch": "main",
        "paths": [
            "charts/backend"
        ]
    }
}
```
:::

**返回参数说明**

| 参数名            | 说明                 | 类型                                      |
| ----------------- | -------------------- | ----------------------------------------- |
| `successServices` | 创建成功的服务名称列表 | []string                                  |
| `failedServices`  | 创建失败的服务列表   | [][FailedHelmService](#FailedHelmService-1) |

<h4 id="FailedHelmService-1">FailedHelmService 参数说明</h4>

| 参数名  | 说明             | 类型   |
| ------- | ---------------- | ------ |
| `path`  | 创建失败的 Chart 路径 | string |
| `error` | 失败原因         | string |

**返回示例**

::: details
```json
{
    "successServices": [
        "backend"
    ],
    "failedServices": []
}
```
:::

``` json
    "auto_sync": true,

    "project_key": "multi-chart",
    "service_name": "api-test",
    "template_name": "general-chart",
    "values_yaml": "aa: bb\ncc: dd",
```
