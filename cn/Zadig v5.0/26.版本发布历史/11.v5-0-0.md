2026 年 7 月 31 日，Zadig 正式发布 v5.0.0 版本。

## 功能列表

**AI 智能体**
- AI 发布专员：工作流任务，结合变更与发布上下文输出风险结论，支持人工确认
- AI 审查专员：代码审查模块内置 AI 审查，支持规则配置，结果回写 MR 评论区
- AI 任务：工作流支持对接自定义 Agent 或模型，执行智能任务
- Zadig CLI & Skills 一期：开放外部 Agent 调用能力

**服务与环境**
- 服务管理和工作流部署支持 CR 资源
- 环境服务视图支持展示 Job 和 Daemonset 类型资源
- 服务配置内置新增集群名称变量
- Helm 环境增加服务配置差异检测
- YAML 环境删除服务允许不删除指定资源
- 主机环境支持别名

**工作流**
- 工作流支持和模板强绑定
- 工作流支持任务级别通知
- 部署任务支持 Daemonset 资源更新
- APISIX 变更任务支持输出配置 ID 信息
- JIRA 任务支持状态回显
- Jenkins 任务支持列出文件夹内任务
- 全局变量支持动态变量类型
- 变量支持设置为必填选项
- 任务和通知支持获取 Git 触发的 Payload 信息
- 执行备注支持设置为必填
- 执行记录列字段支持关联发布计划
- 审批标题支持自定义
- Git 触发器支持正则匹配 Tag 触发
- 执行准备阶段支持显示 Pod 事件
- 测试任务支持变量输入

**发布计划**
- 富文本支持插入表格
- Hook 外部系统 payload 增加发布项负责人信息
- 操作日志细化
- 多人同时编辑增加提示

**系统集成与开放性**
- AI 模型集成支持多个模型接入
- Chart 仓库支持配置公开 Chart 仓库
- 账号系统支持集成海外 Lark
- 操作日志单独权限控制
- Dind 支持 TLS
- 企业管理增加版本信息开关
- 执行工作流 OpenAPI 支持通用任务代码信息透传
- 新增从代码库创建 K8s YAML 服务 OpenAPI
- 新增从 私有库 / 公有库 / Chart仓库 来源创建 Helm 服务 OpenAPI
- 新增自定义工作流创建和更新 OpenAPI
- 新增查询工作流手动执行上下文及执行手动阶段 OpenAPI
- 新增获取当前用户身份 OpenAPI


**优化与修复**
- 优化效能数据计算，排除调试工作流数据
- 优化等待手工执行状态通知卡片样式
- 优化 APISIX 变更任务配置及执行操作
- 优化工作流 DMS 任务工单搜索
- 优化容器调试复制粘贴问题
- 优化 Apollo YAML 配置校验
- 优化 Nacos 配置报错信息
- 优化发布计划保存草稿后镜像分发中显示完整镜像
- 服务回滚前增加检查镜像是否存在判断
- 容器服务部署日志中显示 Pod 数量
- 修复发布计划中看不到工作流执行记录和链接
- 修复发布计划拖动顺序权限问题
- 修复项目概览修改人员信息和修改时间不一致问题
- 修复发布计划&触发器无法选择 Jenkins Job 问题
- 修复调用删除服务 OpenAPI 未删干净问题
- 修复执行工作流 OpenAPI 未带上审批发起人信息问题
- 修复 Chart 模板选择根目录重选时报错问题
- 修复克隆工作流调试任务时多选变量值获取错误问题
- 修复蓝绿部署手动执行阶段时状态被清除问题
- 修复测试在主机上执行通过率判断失效问题
- 修复主机执行代码扫描报错问题
- 若干修复与优化


## 版本升级过程

::: warning
若使用的 MongoDB 以 Replica Set 模式部署，请确认未使用 admin/local/config/test 等系统库作为 Zadig 的业务库；如有使用，请先手动迁移数据。

若当前系统版本 < v4.3.0，请先升级到 v4.3.0，具体升级步骤请参考 [v4.3.0 升级方式](/cn/Zadig%20v5.0/release-notes/v4.3.0/#版本升级过程)，然后再按照以下方式升级到 v5.0.0。
:::
