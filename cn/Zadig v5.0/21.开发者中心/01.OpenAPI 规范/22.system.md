## 获取 Zadig CLI 上下文

获取当前 API Token 对应的用户身份和请求 ID。系统管理员还可获取 Zadig 版本及许可证信息。该接口可用于 Zadig CLI 或其他 API 客户端在执行操作前确认连接身份与服务端能力。

### 请求

```
GET /openapi/system/cli/context
```

### 返回说明

| 参数名                  | 类型     | 描述                         |
| ----------------------- | -------- | ---------------------------- |
| `user`                  | object   | 当前认证用户                 |
| `user.uid`              | string   | 用户 UID                     |
| `user.name`             | string   | 用户名称                     |
| `user.account`          | string   | 用户账号                     |
| `user.identity_type`    | string   | 用户身份类型                 |
| `edition`               | string   | Zadig 版本类型，系统管理员返回 |
| `license_status`        | string   | 许可证状态，系统管理员返回     |
| `features`              | []string | 当前许可证支持的功能列表，系统管理员返回 |
| `server_version`        | string   | Zadig 服务端版本，系统管理员返回 |
| `request_id`            | string   | 当前请求 ID，可用于问题排查  |

### 返回示例

```json
{
    "user": {
        "uid": "45eb4cf9-3715-11f1-8976-42f9e9fb45c1",
        "name": "admin",
        "account": "admin",
        "identity_type": "system"
    },
    "edition": "enterprise",
    "license_status": "active",
    "features": [],
    "server_version": "5.0.0",
    "request_id": "7f64d2f5-47a7-4f61-9a38-2018037cab28"
}
```

普通用户返回示例：

```json
{
    "user": {
        "uid": "45eb4cf9-3715-11f1-8976-42f9e9fb45c1",
        "name": "developer",
        "account": "developer",
        "identity_type": "user"
    },
    "request_id": "7f64d2f5-47a7-4f61-9a38-2018037cab28"
}
```

## 列出系统操作日志

### 请求

```
GET /openapi/system/operation
```

### Query

| 参数名     | 类型   | 描述                                                                                                         | 必填 |
| ---------- | ------ | ------------------------------------------------------------------------------------------------------------ | ---- |
| searchType | string | 搜索类型，可选值：<br>`all`：全部<br>`project`：项目<br>`user`：用户<br>`function`：功能<br>`status`：状态码 | 是   | 是 |
| projectKey | string | 项目标识                                                                                                     | 否   |
| username   | string | 用户名                                                                                                       | 否   |
| function   | string | 功能                                                                                                         | 否   |
| status     | int    | 状态码                                                                                                       | 否   |
| perPage    | int    | 每页数量                                                                                                     | 是   |
| page       | int    | 页码                                                                                                         | 是   |
