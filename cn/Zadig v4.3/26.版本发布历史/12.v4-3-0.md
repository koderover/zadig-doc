2026 年 5 月 13 日，Zadig 正式发布 v4.3.0 版本。

## 功能列表

**AI 能力**
- AI 环境巡检 - 自动化检测集群健康状态
- AI 效能诊断 - 一键分析项目效率瓶颈
- AI 模块正式纳入标准产品，不再作为独立站点

**工作流与发布计划**
- 工作流执行支持选择不使用缓存
- 工作流部署任务配置中环境支持可选
- 工作流部署任务仅更新镜像时不变更仅导入状态
- 工作流 DMS 数据变更任务支持串行执行
- 工作流通知支持手动执行事件并通知阶段执行人
- Git 触发器监听 MR 事件时过滤描述修改操作
- 工作流审批详情支持格式化时间变量 <span v-pre>`{{.workflow.task.datetime}}`</span>
- 工作流列字段添加发布计划
- 发布计划支持复制
- 发布计划支持日历视图
- 发布计划及模板支持拖拽排序
- 发布计划完成阶段保留工作流详情
- 发布计划飞书审批支持抄送和用户组
- 发布计划外部检测 Hook 增加检测说明
- 环境中服务配置支持保存草稿

**安全与权限**
- 企业授权安全逻辑增强
- 系统支持多因素认证 (MFA)
- API Token 加密显示，支持重置
- 用户管理增加 API Token 开关控制
- 登录安全增强：验证码防复用、用户名防枚举、登录信息加密
- 新增系统只读角色 global-read-only
- 业务目录增加新建、更新、删除权限控制
- 环境权限细化，支持重启、回滚、调整副本数独立权限控制

**开放性与系统扩展**
- 飞书项目 ↔ Zadig：发布状态双向实时同步
- OpenClaw 插件：Zadig DevOps 能力通过插件对外开放
- MCP Server 一期：Zadig 可作为 MCP Server，供 AI 工具链调用
- K8s YAML 服务模板支持从代码库同步
- 工作流自定义任务支持变量输出
- 用户列表 OpenAPI 新增登录时间字段


**问题修复与体验优化**
- 主机管理列表显示 Agent 版本
- 修复工作流执行记录搜索中环境列表不正确问题
- 修复工作流 apollo 更新 YAML 类型配置报错问题
- 修复工作流部署 Statefulset 情况下失败后无法幂等更新问题
- 优化业务目录服务名称显示效果
- 优化 Chart 服务配置从代码库同步选择目录交互
- 优化使用模板新建的服务版本更新时操作日志信息
- 优化代码源错误提示
- 其他若干优化及修复

## 业务变更声明

v4.3 版本对企业版本授权进行了安全加固，专家版和企业版升级完成后需配置新的授权许可证。

## 版本升级过程

::: warning
若使用的 MongoDB 以 Replica Set 模式部署，请确认未使用 admin/local/config/test 等系统库作为 Zadig 的业务库；如有使用，请先手动迁移数据。

若当前系统版本 < v4.2.1，请先升级到 v4.2.1，具体升级步骤请参考 [v4.2.1 升级方式](/cn/Zadig%20v4.3/release-notes/v4.2.1/#版本升级过程)，然后再按照以下方式升级到 v4.3.0。
:::

请根据不同的安装方式执行对应的升级过程：

- [Helm 命令安装](/cn/Zadig%20v4.3/install/helm-deploy/#升级)
